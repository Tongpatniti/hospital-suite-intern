=====================================================================
คู่มือการใช้งานระบบแจ้งซ่อม (Repair System User Guide)
=====================================================================

คู่มือนี้อธิบายการใช้งานระบบแจ้งซ่อมในการทำงานจริง ทุกส่วนและทุกบทบาท
อ้างอิงจากการทำงานของโปรแกรม (หน้าเว็บ repair-app และ API backend)

สารบัญ
---------------------------------------------------------------------
 1. ภาพรวมระบบ
 2. บทบาทและสิทธิ์การใช้งาน
 3. บัญชีผู้ใช้และการขอสิทธิ์
 4. การเข้าสู่ระบบ และเมนู Sidebar
 5. การแจ้งซ่อม (สร้างใบซ่อมใหม่)
 6. หน้ารายการแจ้งซ่อม
 7. หน้ารายละเอียดใบซ่อม
 8. สถานะของใบซ่อมและผู้ที่เปลี่ยนได้
 9. ขั้นตอนการทำงานของแต่ละบทบาท
10. การโอนงาน ผู้ร่วมซ่อม และบันทึกความคืบหน้า
11. ไฟล์แนบ (รูปและเอกสาร)
12. การอนุมัติ PO และการอนุมัติราคาซ่อมภายนอก
13. ประวัติการซ่อม ประวัติการทำงาน และประวัติการยื่น PO
14. ประวัติการตั้งค่า (Audit Log)
15. ตั้งค่าระบบ
16. การแจ้งเตือน และ SLA
17. คำถามที่พบบ่อย
18. ข้อควรทราบสำหรับการใช้งาน


=====================================================================
1. ภาพรวมระบบ
=====================================================================

ระบบแจ้งซ่อมใช้แจ้งซ่อมและติดตามงานซ่อมของครุภัณฑ์ มี 3 ประเภทงาน:

  - คอมพิวเตอร์ (COMPUTER)        เช่น เครื่องคอมพิวเตอร์ จอภาพ เครื่องพิมพ์
  - เครื่องมือแพทย์ (MEDICAL)     เช่น Infusion pump, เครื่องวัดความดัน
  - ทั่วไป (GENERAL)              เช่น เครื่องปรับอากาศ ระบบไฟฟ้า เฟอร์นิเจอร์

แต่ละใบซ่อมมีเลขที่รูปแบบ RP-YYNNNN (เช่น RP-690016) และเคลื่อนผ่านหลายสถานะ
ตั้งแต่ "แจ้งซ่อม" จนถึง "ปิดงาน" หรือ "ยกเลิก" หรือ "รอจำหน่าย"

ความสามารถหลัก
  - ทุกตำแหน่งที่เข้าใช้ระบบแจ้งซ่อมได้ทุกประเภท (คอมพิวเตอร์/เครื่องมือแพทย์/ทั่วไป)
  - แจ้งซ่อมได้ทั้งครุภัณฑ์ที่มีรหัส และสิ่งของที่ไม่มีรหัสครุภัณฑ์
  - ระบุยี่ห้อ และระยะเวลาที่คาดไว้ในการซ่อม (วัน)
  - ซื้ออะไหล่ผ่านขั้นตอน PO โดยผู้อนุมัติ PO เป็นผู้อนุมัติ
  - ส่งซ่อมภายนอกได้ לאחרอนุมัติราคาที่ร้านเสนอ
  - กรณีซ่อมไม่ได้/ไม่คุ้ม ให้ช่างตรวจซ้ำและส่งรอจำหน่าย
  - มีหน้าประวัติการซ่อม ประวัติการทำงาน และประวัติการยื่น PO แยกกัน

ทุกการเปลี่ยนสถานะ การโอนงาน การแก้ไขข้อมูลสำคัญ และการแจ้งเตือน
จะถูกบันทึกไว้เป็นประวัติ

2. บทบาทและสิทธิ์การใช้งาน
=====================================================================

ผู้ใช้หนึ่งคนอาจมีได้หลายบทบาท สิทธิ์กำหนดโดยผู้ดูแลระบบ

2.1 ผู้แจ้งซ่อม (Requester)
    - แจ้งซ่อมได้ทุกประเภท (คอมพิวเตอร์ / เครื่องมือแพทย์ / ทั่วไป)
    - เห็นใบซ่อมของตนเองในแท็บ "แจ้งซ่อมของฉัน"
      และในหน้าประวัติการซ่อมจะเห็นเฉพาะใบของตนเอง
      (แท็บอื่นในหน้ารายการแสดงใบของทุกคนในประเภทที่ตนมีสิทธิ์)
    - ติดตามใบซ่อมของตนเองและใบที่ติดตาม
    - ตรวจรับงานซ่อม ให้คะแนน 1-5 ดาว หรือส่งกลับซ่อม
    - ยกเลิกใบซ่อมตามสถานะที่กำหนด (ต้องระบุเหตุผล)
    - เปิดงานที่ปิดแล้วอีกครั้งไม่ได้ (การเปิดงานอีกครั้งทำได้เฉพาะ
      ช่างผู้มีสิทธิ์ประเภทนั้นหรือผู้ดูแลระบบ)

2.2 ช่างซ่อม (Technician) แยกตามประเภท
    - รับงาน / เริ่มดำเนินงาน (ระบุระยะเวลาที่คาดไว้เป็นจำนวนวัน)
    - สั่งซื้ออะไหล่ / ส่งซ่อมภายนอก (เสนอร้านได้)
    - รับอะไหล่แล้วซ่อมต่อ / ตรวจรับเครื่องจากร้านแล้วซ่อมต่อ
    - แจ้งซ่อมเสร็จ (ระบุผลการซ่อมและรายละเอียดการซ่อม
      แนบรูปผลการซ่อมได้ตามต้องการ)
    - ตรวจซ้ำเมื่อซ่อมไม่ได้/ไม่คุ้ม แล้วเลือกซ่อมต่อหรือส่งรอจำหน่าย
    - เปลี่ยนประเภทครุภัณฑ์ (มีรหัส / ไม่มีรหัส) พร้อมระบุเหตุผล
    - โอนงานให้ช่างคนอื่นที่มีสิทธิ์ประเภทเดียวกัน
    - เพิ่ม / นำผู้ร่วมซ่อมออก (เฉพาะช่างผู้รับผิดชอบ)
    - บันทึกความคืบหน้า (เฉพาะสถานะกำลังดำเนินงาน)
    - ช่างคอมพิวเตอร์จะไม่เห็นงานเครื่องมือแพทย์ และในทางกลับกัน
      ยกเว้นมีสิทธิ์ของทั้งสองประเภท

2.3 พัสดุ (Supply)
    - รับเรื่องอะไหล่ และส่งขออนุมัติ PO (กรอกเลข PO)
    - เริ่มจัดซื้อ / บันทึกอะไหล่ถึงคลัง / บันทึกราคาจริงของอะไหล่
    - รับเรื่องส่งซ่อมภายนอก / เลือกร้านและกรอกราคาที่ร้านเสนอ
      แล้วส่งขออนุมัติราคา / ส่งร้าน / รับเครื่องคืน (กรอกค่าซ่อม)
    - เห็นงานทุกประเภท

2.4 ผู้อนุมัติ PO (PO Approver)
    - เห็นเฉพาะใบที่รออนุมัติ PO และรออนุมัติราคาซ่อมภายนอก
      (ถ้ามีบทบาทอื่นร่วมด้วย จะเห็นแท็บของบทบาทนั้นด้วย)
    - อนุมัติ PO หรือไม่อนุมัติ (ต้องระบุเหตุผล)
    - อนุมัติหรือไม่อนุมัติราคาซ่อมภายนอก (ต้องระบุเหตุผลเมื่อไม่อนุมัติ)
    - เห็นงานทุกประเภท

2.5 ผู้ดูแลระบบ (Admin)
    - เห็นทุกใบซ่อม ทุกสถานะ และทุกประเภท
    - ทำได้ทุกขั้นตอนตามสิทธิ์ของระบบ
    - ตั้งค่าระบบและกฎ SLA
    - ดูประวัติการตั้งค่า (Audit Log)

หมายเหตุ: ทุกตำแหน่งแจ้งซ่อมได้ทั้ง 3 ประเภท
ผู้ใช้จะเห็นเฉพาะใบซ่อมของประเภทที่ตนมีสิทธิ์ ยกเว้นพัสดุ ผู้อนุมัติ PO
และผู้ดูแลระบบ ซึ่งเห็นทุกประเภท แต่ใบที่ตนเองแจ้งจะเห็นเสมอ


=====================================================================
3. บัญชีผู้ใช้และการขอสิทธิ์
=====================================================================

3.1 การได้รับบัญชี
    - ผู้ดูแลระบบของหน่วยงานเป็นผู้สร้างบัญชีและกำหนดสิทธิ์ให้
    - ติดต่อผู้ดูแลระบบเพื่อขอ Username และรหัสผ่านเริ่มต้น
    - หลังเข้าสู่ระบบครั้งแรก ควรเปลี่ยนรหัสผ่านเริ่มต้นเป็นของคุณเอง
      ที่หน้า Hub (ดูหัวข้อ 4.4) หรือแจ้งผู้ดูแลระบบให้เปลี่ยนให้
    - ห้ามแชร์บัญชีกับผู้อื่น ทุกการดำเนินการจะถูกบันทึกภายใต้ชื่อผู้ใช้

3.2 การขอสิทธิ์เพิ่มหรือเปลี่ยนบทบาท
    - ติดต่อผู้ดูแลระบบพร้อมระบุ ชื่อ แผนก ประเภทงานที่ต้องดูแล
      และบทบาทที่ต้องการ (แจ้งซ่อม / ช่าง / พัสดุ / ผู้อนุมัติ PO)
    - ไม่มีสิทธิ์ที่ตรงกับงาน ให้แจ้งผู้ดูแลระบบให้ตรวจสอบ


=====================================================================
4. การเข้าสู่ระบบ และเมนู Sidebar
=====================================================================

4.1 การเข้าสู่ระบบ
    1) เปิดหน้าเว็บระบบแจ้งซ่อม
    2) กรอก Username และ Password แล้วกดเข้าสู่ระบบ
       (ช่องรหัสผ่านมีไอคอนรูปตา กดเพื่อแสดง/ซ่อนรหัสผ่านได้)
    3) หรือเข้าจากหน้า Hub ระบบจะเข้าสู่ระบบให้อัตโนมัติ

4.2 เมนู Sidebar (แสดงตามสิทธิ์ของผู้ใช้)

    [รายการแจ้งซ่อม]                 หน้ารายการใบซ่อมทั้งหมด (ทุกประเภท)
    [Back to Hub]                    กลับไปหน้า Hub
    กลุ่ม "แจ้งซ่อม"                 แจ้งซ่อมทั่วไป / คอมพิวเตอร์ / เครื่องมือแพทย์
                                     (เห็นครบทั้ง 3 ประเภททุกบทบาท)
    กลุ่ม "รายการการแจ้งซ่อม"         รายการใบซ่อมแยกตามประเภท
                                     (เห็นเฉพาะประเภทที่มีสิทธิ์ดู)
    ประวัติการซ่อม                   ประวัติและสถิติการซ่อม
    ประวัติการทำงาน                  ใบที่ตนรับผิดชอบ/ร่วมซ่อม/ดำเนินการ
                                     (ช่าง และพัสดุ)
    ประวัติการยื่น PO                รายการ PO ที่ตนยื่น (พัสดุ และผู้ดูแลระบบ)
    ประวัติการตั้งค่า                 Audit Log (เฉพาะผู้มีสิทธิ์)
    ตั้งค่าระบบ                      ค่าตั้งระบบและกฎ SLA (เฉพาะผู้ดูแลระบบ)

    ลำดับเมนู: Back to Hub, รายการแจ้งซ่อม, กลุ่มแจ้งซ่อม,
    กลุ่มรายการการแจ้งซ่อม, แล้วจึงกลุ่ม "ทั่วไป" (ประวัติและตั้งค่า)

    ไอคอนประเภท: ทั่วไป, คอมพิวเตอร์, เครื่องมือแพทย์

4.3 การแจ้งเตือน
    มุมขวาบนมีปุ่มรูประฆัง แสดงจำนวนที่ยังไม่ได้อ่าน
    ระบบโหลดรายการใหม่ทุก 1 นาที
    กดรายการเพื่อไปยังใบซ่อมนั้น และเมื่อเปิดดูรายการ
    ระบบจะทำเครื่องหมายว่าอ่านแล้วทั้งหมด

4.4 การเปลี่ยนรหัสผ่าน
    ที่หน้า Hub กดปุ่ม "เปลี่ยนรหัส" มุมขวาบน แล้วกรอก
    รหัสผ่านปัจจุบัน รหัสผ่านใหม่ และยืนยันรหัสผ่านใหม่
    (รหัสผ่านใหม่ยาวอย่างน้อย 4 ตัวอักษร และต้องตรงกับช่องยืนยัน)
    ในหน้าต่างนี้กดไอคอนรูปตาเพื่อแสดง/ซ่อนรหัสผ่านได้

5. การแจ้งซ่อม (สร้างใบซ่อมใหม่)
=====================================================================

5.1 ขั้นตอน
    1) เลือกเมนู "แจ้งซ่อม" แล้วเลือกประเภท (เช่น แจ้งซ่อมคอมพิวเตอร์)
    2) เลือกครุภัณฑ์
       - ค้นหาด้วยรหัสหรือชื่อ แล้วเลือกจากรายการ
       - หรือติ๊ก "ไม่มีรหัสครุภัณฑ์" แล้วกรอกชื่อสิ่งของ (บังคับ)
    3) ระบบตรวจว่าเครื่องนี้มีใบซ่อมที่ยังไม่ปิดอยู่หรือไม่
       - ถ้ามี เลือก "ติดตามใบเดิม" หรือ "แจ้งใหม่ (อาการต่างกัน)"
         โดยการแจ้งใหม่ต้องกรอกเหตุผล
    4) เลือกความเร่งด่วน: ต่ำ / ปกติ / สูง / วิกฤต
    5) กรอกสถานที่ตั้ง (ระบบเติมให้จากครุภัณฑ์ได้)
    6) กรอกยี่ห้อ (บังคับ ทั้งกรณีมีรหัสและไม่มีรหัสครุภัณฑ์)
    7) กรอกอาการเสีย (บังคับ)
    8) แนบรูปอาการเสียหรือเอกสาร (ไม่บังคับ)
    9) กด "ส่งใบแจ้งซ่อม"

    ผลลัพธ์: ได้เลขใบซ่อม RP-YYNNNN ใบอยู่สถานะ "แจ้งซ่อม"
    และแจ้งเตือนช่างที่มีสิทธิ์ประเภทนั้นทันที

5.2 การติดตามใบเดิม
    ใบที่ผู้ใช้เลือก "ติดตามใบเดิม" จะเพิ่มผู้ใช้เป็นผู้ติดตาม
    ไม่ได้สร้างใบซ่อมใหม่ ผู้ติดตามจะได้รับการแจ้งเตือนความคืบหน้า
    ผู้ติดตามเลิกติดตามได้จากหน้ารายละเอียดใบซ่อม

6. หน้ารายการแจ้งซ่อม
=====================================================================

6.1 แท็บตามบทบาท
    ผู้แจ้งซ่อม : แจ้งซ่อมของฉัน, รอช่างรับงาน, รอตรวจรับ,
                  รายการที่เสร็จสิ้น, ยกเลิก/ปฏิเสธ, ทั้งหมด
    ช่าง       : รอช่างรับงาน (แท็บแรก), งานที่ฉันรับผิดชอบ,
                  แจ้งซ่อมของฉัน, รอตรวจรับ, งานที่ยังไม่ปิด,
                  รายการที่เสร็จสิ้น, ยกเลิก/ปฏิเสธ, ทั้งหมด
    พัสดุ      : งานพัสดุ, งานที่ฉันดำเนินการ, แจ้งซ่อมของฉัน,
                  รอช่างรับงาน, รอตรวจรับ, งานที่ยังไม่ปิด,
                  รายการที่เสร็จสิ้น, ยกเลิก/ปฏิเสธ, ทั้งหมด
    ผู้อนุมัติ PO: รออนุมัติ PO / ราคาซ่อม (แสดงใบที่รออนุมัติ PO
                  และรออนุมัติราคาซ่อมภายนอก), แจ้งซ่อมของฉัน
    ผู้ดูแลระบบ : งานที่ยังไม่ปิด, รอรับงาน, รอตรวจรับ, งานพัสดุ,
                  รายการที่เสร็จสิ้น, ยกเลิก/ปฏิเสธ, ทั้งหมด

    หมายเหตุ: ช่างจะเห็นแท็บ "รอช่างรับงาน" เป็นแท็บแรกเสมอ
    ผู้ใช้ที่มีหลายบทบาทจะเห็นแท็บของทุกบทบาทรวมกัน
    และทุกบทบาทเห็นแท็บ "แจ้งซ่อมของฉัน" เพราะทุกตำแหน่ง
    แจ้งซ่อมได้ทุกประเภท
    ส่วนแท็บ "รออนุมัติ PO / ราคาซ่อม" แสดงเฉพาะผู้ใช้ที่มีบทบาท
    ผู้อนุมัติ PO เพียงบทบาทเดียว

    ด้านบนแท็บมีการ์ดสรุป 4 ใบ (นับเฉพาะใบที่ยังไม่ถูกปิดหรือยกเลิก
    ในชุดที่กำลังแสดง)
        งานที่แสดงและยังไม่ปิด / เกินเวลาที่กำหนด /
        ใกล้ครบเวลา / รอผู้แจ้งตรวจรับ

6.2 การกรองและค้นหา
    - ประเภทงาน: หน้ารายการที่เปิดจากเมนูประเภท จะแสดงเฉพาะประเภทนั้น
      หน้ารายการจากเมนู "รายการแจ้งซ่อม" จะแสดงทุกประเภท
      ตัวเลือกประเภทถูกล็อกไว้ทั้งสองกรณี
    - ช่องค้นหา: ค้นจากเลขใบซ่อม ชื่อ หรือรหัสครุภัณฑ์
    - ปุ่มสลับมุมมอง (ขวาของแถบแท็บ):
        ค่าเริ่มต้นเรียง "ของฉันก่อน" และปุ่มเขียนว่า
        "แสดงทั้งหมด (ไม่จัดลำดับของฉันก่อน)"
        กดแล้วจะแสดงทั้งหมดโดยไม่ดันงานของฉันขึ้นก่อน
        และปุ่มจะเปลี่ยนเป็น "จัดลำดับ: ของฉันก่อน"
      หมายเหตุ: หน้ารายการโหลดได้สูงสุด 300 ใบต่อครั้ง
      ตามลำดับการเรียงที่กำลังแสดงอยู่

6.3 การเรียงลำดับ
    ค่าเริ่มต้นเรียงงานที่ค้างนานเทียบกับเวลาที่กำหนดไว้บนสุด
    (งานที่เกินกำหนดจะอยู่ก่อน) กดที่หัวตารางเพื่อเรียงเอง
    (เลขใบซ่อม / สถานะ / SLA / แจ้งเมื่อ)
    - กดครั้งแรก: มากไปน้อย (▼)
    - กดอีกครั้ง: น้อยไปมาก (▲)

6.4 สัญลักษณ์ SLA
    เขียว    ปกติ ยังไม่ถึงกำหนด
    เหลือง   ใกล้ครบกำหนด (ถึง 80% ของเวลาที่กำหนด)
    แดง      ครบหรือเกินกำหนดแล้ว

    กดที่แถวใดก็ได้เพื่อเปิดหน้ารายละเอียดใบซ่อม

6.5 คอลัมน์ในตาราง
    เลขใบซ่อม          เลขที่ใบซ่อม
    ครุภัณฑ์ / อาการ    ชื่อเรื่อง รหัสครุภัณฑ์ แผนก ความเร่งด่วน
    ประเภท              คอมพิวเตอร์ / เครื่องมือแพทย์ / ทั่วไป
    สถานะ              สถานะปัจจุบัน (แสดงป้าย "ประกัน" ถ้าอยู่ในประกัน)
    SLA                 เวลาที่ค้างในสถานะเทียบกับเวลาที่กำหนด
    ช่าง                ช่างผู้รับผิดชอบ
    ระยะเวลา (วัน)      จำนวนวันจากวันที่รับงาน (หรือวันที่แจ้งถ้ายังไม่รับงาน)
                        ถึงวันที่ปิดงาน (หรือปัจจุบัน)
    แจ้งเมื่อ            วันที่และเวลาที่แจ้ง


=====================================================================
7. หน้ารายละเอียดใบซ่อม
=====================================================================

ส่วนประกอบของหน้า
    หัวใบซ่อม          เลขใบซ่อม ชื่อเรื่อง สถานะ ประเภท ความเร่งด่วน
    ปุ่มดำเนินการ      ปุ่มติดตาม/เลิกติดตาม, เปลี่ยนประเภทครุภัณฑ์
                       (ช่างผู้รับผิดชอบ), โอนงาน (ช่างผู้รับผิดชอบ/
                       ผู้ดูแลระบบ), และปุ่มสถานะถัดไปตามสิทธิ์
    Timeline           ประวัติการเปลี่ยนสถานะและการแจ้งเตือน SLA
    ความคืบหน้าการซ่อม บันทึกความคืบหน้า (เฉพาะสถานะกำลังดำเนินงาน)
    ผู้ร่วมซ่อม        รายชื่อผู้ร่วมซ่อม
    รายการอะไหล่        อะไหล่ที่ขอซื้อ และราคาจริง
    ใบสั่งซื้อ (PO)    เลข PO สถานะ และผู้อนุมัติ
    ส่งซ่อมภายนอก     ร้าน ราคาที่ร้านเสนอ วันที่ส่ง/รับคืน
                       และค่าซ่อมจริง
    ไฟล์แนบ            รูปและเอกสาร
    ข้อมูลครุภัณฑ์    ข้อมูล ณ วันที่แจ้ง รวมยี่ห้อ ระยะเวลาที่คาดไว้
                       ผู้ซ่อมเสร็จ และผู้ปิดงาน
    ผู้ติดตาม          ผู้ที่ติดตามใบนี้
    ซ่อมครั้งก่อน      ใบซ่อมก่อนหน้าของครุภัณฑ์เดียวกัน (สูงสุด 3 ใบ)

    หัวใบซ่อมจะแสดง "เปิดซ้ำ N ครั้ง" เมื่อเคยเปิดงานหลังปิด
    Timeline รวมรายการแจ้งเตือน SLA (แถบแดง) ไว้ด้วย
    ถ้าใบนี้แจ้งซ้ำกับใบเดิม จะมีแถบเตือนพร้อมเหตุผลที่แจ้งใหม่

    สิทธิ์กดปุ่มเปลี่ยนสถานะคิดจากสิทธิ์ประเภทงานของผู้ใช้
    (ไม่ผูกกับว่าเป็น "งานที่ฉันรับผิดชอบ" หรือไม่)
    แต่การโอนงาน เปลี่ยนประเภทครุภัณฑ์ และจัดการผู้ร่วมซ่อม
    ทำได้เฉพาะช่างผู้รับผิดชอบหรือผู้ดูแลระบบ

    ในส่วนส่งซ่อมภายนอกจะแสดงชื่อผู้รับผิดชอบและชื่อร้าน/บริษัทในบรรทัด
    เดียวกัน รูปแบบ "ส่งเรื่องโดย <ชื่อผู้รับผิดชอบ> · <ชื่อร้าน/บริษัท>"

    ปุ่ม "เปลี่ยนประเภทครุภัณฑ์" ใช้เมื่อรหัสครุภัณฑ์ไม่ตรงกับเครื่องจริง
    ทำได้โดยช่างผู้รับผิดชอบในสถานะรับงานซ่อมหรือกำลังดำเนินงาน
    เลือกครุภัณฑ์ใหม่ประเภทเดียวกันหรือ "ไม่มีรหัสครุภัณฑ์" และต้องระบุ
    เหตุผล ระบบจะคืนสถานะทะเบียนเครื่องเดิมเป็น "ใช้งานได้"

8. สถานะของใบซ่อม
=====================================================================

8.1 รายชื่อสถานะ

  รหัส              ชื่อที่แสดง                       ผู้รับผิดชอบขั้นนี้
  ----------------  --------------------------------  -----------------
  NEW               แจ้งซ่อม                          ช่าง
  ACCEPTED          รับงานซ่อม                        ช่าง
  IN_PROGRESS       กำลังดำเนินงาน                    ช่าง
  WAIT_PART         สั่งซื้ออะไหล่                    พัสดุ
  PART_APPROVAL     พัสดุรับเรื่องอะไหล่              พัสดุ
  PO_PENDING        รออนุมัติ PO                      ผู้อนุมัติ PO
  PO_APPROVED       ได้รับการอนุมัติ PO แล้ว          พัสดุ
  PART_PURCHASING   กำลังจัดซื้ออะไหล่                 พัสดุ
  PART_ARRIVED      อะไหล่ถึงคลัง                     ช่าง
  WAIT_EXTERNAL     แจ้งส่งซ่อมภายนอก                 พัสดุ
  EXT_APPROVAL      รออนุมัติส่งซ่อม                  พัสดุ
  EXT_PRICE_PENDING รออนุมัติราคาซ่อมภายนอก           ผู้อนุมัติ PO
  EXT_PRICE_APPROVED อนุมัติราคาแล้ว รอส่งซ่อม        พัสดุ
  EXT_SENT          ส่งร้านภายนอกแล้ว                 พัสดุ
  EXT_RECEIVED      รับอุปกรณ์คืนแล้ว                 ช่าง
  UNREPAIRABLE_CHECK ช่างตรวจซ้ำ (ซ่อมไม่ได้/ไม่คุ้ม) ช่าง
  DISPOSAL          รอจำหน่าย                        สิ้นสุด (ปิดใบ)
  DONE              รอตรวจรับ                         ผู้แจ้งซ่อม
  CLOSED            ปิดงาน                            ผู้แจ้งซ่อม
  CANCELLED         ยกเลิก                            สิ้นสุด

  หมายเหตุ: DISPOSAL เป็นสถานะสิ้นสุด ระบบจะปิดใบซ่อม
  (ผลการซ่อม = ซ่อมไม่ได้) และปรับสถานะทะเบียนครุภัณฑ์เป็น "รอจำหน่าย"

8.2 การเปลี่ยนสถานะที่อนุญาต

  จาก                    ไปยัง (ที่อนุญาต)
  ---------------------  ----------------------------------------------
  NEW                    ACCEPTED, CANCELLED
  ACCEPTED               IN_PROGRESS, CANCELLED
  IN_PROGRESS            DONE, WAIT_PART, WAIT_EXTERNAL, CANCELLED
  WAIT_PART              PART_APPROVAL, CANCELLED
  PART_APPROVAL          PO_PENDING, CANCELLED
  PO_PENDING             PO_APPROVED, PART_APPROVAL (ไม่อนุมัติ)
  PO_APPROVED            PART_PURCHASING
  PART_PURCHASING        PART_ARRIVED
  PART_ARRIVED           IN_PROGRESS
  WAIT_EXTERNAL          EXT_APPROVAL, CANCELLED
  EXT_APPROVAL           EXT_PRICE_PENDING, CANCELLED
  EXT_PRICE_PENDING      EXT_PRICE_APPROVED (อนุมัติราคา),
                         EXT_APPROVAL (ไม่อนุมัติราคา + เหตุผล)
  EXT_PRICE_APPROVED     EXT_SENT
  EXT_SENT               EXT_RECEIVED, UNREPAIRABLE_CHECK
  EXT_RECEIVED           IN_PROGRESS
  UNREPAIRABLE_CHECK     IN_PROGRESS (ตรวจซ้ำแล้วซ่อมได้),
                         DISPOSAL (ตรวจซ้ำแล้วส่งรอจำหน่าย + เหตุผล)
  DONE                   CLOSED, IN_PROGRESS (ส่งกลับซ่อม)
  CLOSED                 IN_PROGRESS (เปิดงานอีกครั้ง)
  DISPOSAL               (ไม่มี ถือเป็นสถานะสิ้นสุด)
  CANCELLED              (ไม่มี ถือเป็นสถานะสิ้นสุด)

8.3 ข้อบังคับเมื่อเปลี่ยนสถานะ
    - ยกเลิก (CANCELLED)                 บังคับเหตุผล
    - เริ่มดำเนินงาน (ACCEPTED -> IN_PROGRESS)
                                          บังคับระยะเวลาที่คาดไว้ (วัน)
    - ซ่อมเสร็จ (DONE)                   บังคับระบุรายละเอียดการซ่อม
                                          (รูปผลการซ่อมไม่บังคับ)
    - ส่งซ่อมภายนอก (WAIT_EXTERNAL)       บังคับระบุอาการ/เหตุผล
    - ส่งขออนุมัติราคา (EXT_PRICE_PENDING) บังคับร้านและราคาที่ร้านเสนอ
    - ไม่อนุมัติราคา                      บังคับเหตุผล
    - ไม่อนุมัติ PO                      บังคับเหตุผล
    - ส่งคืนซ่อมไม่ได้ (UNREPAIRABLE_CHECK) บังคับเหตุผล
    - ส่งรอจำหน่าย (DISPOSAL)            บังคับเหตุผล
    - ส่งกลับซ่อม (DONE -> IN_PROGRESS)  บังคับเหตุผล
    - เปิดงานอีกครั้ง (CLOSED -> IN_PROGRESS) บังคับเหตุผล
    - ปิดงาน (CLOSED)                    บังคับให้คะแนน 1-5 ดาว
    - สั่งซื้ออะไหล่                     บังคับรายการอะไหล่ และรูปอย่างน้อย 1 รูปต่อรายการ
    - ส่งซ่อมภายนอก (ฟอร์มส่งร้าน)       บังคับระบุร้าน
    - ค่าซ่อมจากร้าน                     บังคับระบุค่าซ่อม (ยกเว้นกรณีซ่อมไม่ได้/ไม่คุ้ม)
    - วันที่ทุกช่องต้องไม่เป็นวันในอนาคต
    - วันที่รับเครื่องคืนต้องไม่ก่อนวันที่ส่ง

8.4 ผลการซ่อม (เลือกตอนซ่อมเสร็จ)
    ซ่อมได้                          (REPAIRED, ค่าเริ่มต้น)
    ซ่อมไม่ได้ (รอจำหน่าย)           (UNREPAIRABLE)
    ตรวจแล้วไม่พบอาการเสีย           (NOT_FOUND)


=====================================================================
9. ขั้นตอนการทำงานของแต่ละบทบาท
=====================================================================

9.1 ช่างซ่อม (Technician)

  ขั้นที่ 1 รับงาน
    - เปิดใบสถานะ "แจ้งซ่อม" แล้วกด "รับงานซ่อม"
    - ระบบตั้งชื่อคุณเป็นผู้รับผิดชอบ
    - ถ้าครุภัณฑ์มีรหัส สถานะครุภัณฑ์จะเปลี่ยนเป็น "อยู่ระหว่างซ่อม"

  ขั้นที่ 2 เริ่มดำเนินงาน
    - กด "เริ่มดำเนินงาน"
    - กรอกระยะเวลาที่คาดไว้ในการซ่อม (จำนวนวัน) (บังคับ)
    - บันทึกความคืบหน้าได้หลายครั้ง (ดูหัวข้อ 10.3)

  ขั้นที่ 2.1 เปลี่ยนประเภทครุภัณฑ์ (มีรหัส / ไม่มีรหัส)
    - ทำได้โดยช่างผู้รับผิดชอบ ในสถานะรับงานซ่อมหรือกำลังดำเนินงาน
    - กด "เปลี่ยนประเภทครุภัณฑ์" เลือกครุภัณฑ์ใหม่ประเภทเดียวกัน
      หรือ "ไม่มีรหัสครุภัณฑ์" แล้วกรอกเหตุผล (บังคับ)
    - ระบบคืนสถานะทะเบียนของเครื่องเดิมเป็น "ใช้งานได้"
      และตั้งเครื่องใหม่เป็น "อยู่ระหว่างซ่อม"

  ขั้นที่ 3 ถ้าต้องใช้อะไหล่
    - กด "สั่งซื้ออะไหล่" แล้วกรอกรายการ: ชื่อ รหัส จำนวน หน่วย ราคาประมาณ
    - แนบรูปอย่างน้อย 1 รูปต่อรายการอะไหล่ (บังคับ)
    - ยืนยัน ระบบแจ้งพัสดุ
    - เมื่อพัสดุแจ้งว่าอะไหล่ถึงคลัง ให้กด "รับอะไหล่แล้ว ซ่อมต่อ"

  ขั้นที่ 4 ถ้าต้องส่งซ่อมภายนอก
    - กด "ส่งเรื่องซ่อมภายนอก"
    - กรอกอาการ/เหตุผล (บังคับ) และร้านที่แนะนำ (ถ้ามี)
      ช่องร้านเลือกจากรายการที่เคยบันทึกไว้ หรือพิมพ์ชื่อใหม่ได้
    - พัสดุเป็นผู้กรอกราคาที่ร้านเสนอและส่งขออนุมัติ
    - รออนุมัติราคา พัสดุส่งร้านและรับเครื่องคืน
      แล้วกด "ตรวจรับอุปกรณ์และซ่อมต่อ"

  ขั้นที่ 5 ซ่อมเสร็จ
    - กด "ซ่อมเสร็จ"
    - เลือกผลการซ่อม (ซ่อมได้ / ซ่อมไม่ได้ / ตรวจแล้วไม่พบอาการ)
    - กรอกรายละเอียดการซ่อม (บังคับ) และแนบรูปผลการซ่อม (ไม่บังคับ)
    - ยืนยัน ระบบบันทึกคุณเป็น "ผู้ซ่อมเสร็จ" และส่งเรื่องให้ผู้แจ้งตรวจรับ

  กรณีซ่อมไม่ได้ / ไม่คุ้มซ่อม
    - เมื่อพัสดุรับเครื่องคืนและแจ้งซ่อมไม่ได้ ใบจะอยู่สถานะ
      "ช่างตรวจซ้ำ (ซ่อมไม่ได้/ไม่คุ้ม)"
    - ช่างเลือก "ช่างตรวจซ้ำแล้ว ซ่อมต่อได้" เพื่อกลับไปกำลังดำเนินงาน
    - หรือ "ช่างตรวจซ้ำแล้ว ส่งรอจำหน่าย" พร้อมเหตุผล (บังคับ)
      ระบบจะปิดใบซ่อมและตั้งทะเบียนครุภัณฑ์เป็น "รอจำหน่าย"

  ถ้าผู้แจ้งส่งกลับซ่อม
    - ใบจะกลับเป็น "กำลังดำเนินงาน" พร้อมเหตุผลที่ผู้แจ้งระบุ
    - ซ่อมใหม่แล้วกด "ซ่อมเสร็จ" อีกครั้ง

9.2 ผู้แจ้งซ่อม (Requester)

    1) เปิดใบสถานะ "รอตรวจรับ (DONE)"
    2) ตรวจงานซ่อม แล้วเลือก
       - "ตรวจรับและปิดงาน": ให้คะแนน 1-5 ดาว (บังคับ)
         และใส่ข้อเสนอแนะได้
       - "ไม่ผ่าน ส่งกลับซ่อม": กรอกเหตุผล (บังคับ) ใบจะกลับไปที่ช่าง
    3) "ยกเลิกใบซ่อม": ทำได้เมื่อยังไม่เริ่มซ่อมหรือระหว่างดำเนินงาน
       ต้องกรอกเหตุผล (บังคับ)
    4) การ "เปิดงานอีกครั้ง" หลังปิดงานทำได้เฉพาะช่างผู้มีสิทธิ์
       ประเภทนั้นหรือผู้ดูแลระบบ (ต้องระบุเหตุผล) ผู้แจ้งซ่อม
       จะไม่เห็นปุ่มนี้ และเปิดใบที่อยู่สถานะรอจำหน่ายไม่ได้
    5) ผู้แจ้งเห็นใบของตนเองในแท็บ "แจ้งซ่อมของฉัน"
       และเห็นเฉพาะใบของตนเองในหน้าประวัติการซ่อม

9.3 พัสดุ (Supply)

  ส่วนอะไหล่
    1) เมื่อช่างสั่งซื้อ ใบจะเข้าสถานะ "พัสดุรับเรื่องอะไหล่" กดรับเรื่อง
    2) กด "ส่งขออนุมัติ PO" กรอกเลข PO (บังคับ) และวันที่ PO
       (ค่าเริ่มต้นคือวันนี้) แนบเอกสาร PO ได้
    3) รอผู้อนุมัติ PO
       - อนุมัติ: ใบเป็น "ได้รับการอนุมัติ PO แล้ว" กด "เริ่มจัดซื้ออะไหล่"
       - ไม่อนุมัติ: ใบกลับมาที่ "พัสดุรับเรื่องอะไหล่" พร้อมเหตุผล
         ให้แก้ไขแล้วส่งขออนุมัติ PO ใหม่
    4) เมื่ออะไหล่มาถึง กด "อะไหล่ถึงคลังแล้ว"
    5) บันทึกราคาจริงของอะไหล่ในรายการอะไหล่
       ถ้าแก้ราคาที่เคยบันทึกไว้ ระบบส่งเหตุผล "แก้ไขราคาจริง"
       ให้อัตโนมัติและเก็บไว้ในประวัติการตั้งค่า

  ส่วนส่งซ่อมภายนอก
    1) กด "รับเรื่องส่งซ่อม"
    2) กด "ส่งขออนุมัติราคาซ่อมภายนอก"
       - เลือกร้านที่ส่งซ่อม (บังคับ) จากรายการหรือพิมพ์ใหม่
       - กรอกราคาที่ร้านเสนอ (บังคับ)
    3) รอผู้อนุมัติ PO อนุมัติราคา
       - ไม่อนุมัติ: ใบกลับมาที่ "รออนุมัติส่งซ่อม" พร้อมเหตุผล
         ให้เทียบราคาใหม่แล้วส่งขออนุมัติอีกครั้ง
    4) เมื่ออนุมัติแล้ว กด "ส่งร้านภายนอกแล้ว" กรอกวันที่ส่ง (บังคับ)
       (ไม่ต้องกรอกชื่อร้านซ้ำ)
    5) กด "รับเครื่องคืนแล้ว" กรอกวันที่รับคืน (บังคับ) และค่าซ่อม (บังคับ)
       รวมเลขใบแจ้งหนี้/ใบเสร็จ (ถ้ามี)
    6) ถ้าร้านแจ้งซ่อมไม่ได้/ไม่คุ้ม กด
       "รับคืน: ซ่อมไม่ได้/ไม่คุ้ม ส่งช่างตรวจซ้ำ" พร้อมเหตุผล (บังคับ)

9.4 ผู้อนุมัติ PO (PO Approver)

    1) เปิดแท็บ "รออนุมัติ PO / ราคาซ่อม" จะเห็นเฉพาะใบที่รอการอนุมัติ
    2) ตรวจรายการอะไหล่และเอกสาร PO
    3) เลือก
       - "อนุมัติ PO": ใบเป็น "ได้รับการอนุมัติ PO แล้ว"
         แล้วพัสดุกด "เริ่มจัดซื้ออะไหล่"
       - "ไม่อนุมัติ PO": กรอกเหตุผล (บังคับ) ใบกลับไปให้พัสดุ

    การอนุมัติราคาซ่อมภายนอก
       - ใบจะอยู่สถานะ "รออนุมัติราคาซ่อมภายนอก"
       - "อนุมัติราคาซ่อมภายนอก": ใบไปสถานะ "อนุมัติราคาแล้ว รอส่งซ่อม"
       - "ไม่อนุมัติราคา ส่งกลับให้พัสดุ": กรอกเหตุผล (บังคับ)
         ใบกลับไปสถานะ "รออนุมัติส่งซ่อม"
       - ผู้อนุมัติ PO ไม่ได้เป็นผู้ส่งร้านหรือรับเครื่องคืน

    หมายเหตุ: แท็บ "รออนุมัติ PO / ราคาซ่อม" แสดงเฉพาะผู้ใช้ที่มี
    บทบาทผู้อนุมัติ PO เพียงอย่างเดียว ถ้ามีหลายบทบาทให้ค้นใบที่รออนุมัติ
    จากแท็บ "งานที่ยังไม่ปิด" หรือ "ทั้งหมด"

9.5 ผู้ดูแลระบบ (Admin)
    - เห็นและดำเนินการได้ทุกใบ ทุกประเภท และทุกสถานะ
    - โอนงาน เพิ่มผู้ร่วมซ่อม และบันทึกความคืบหน้าได้ในฐานะผู้ดูแล
    - ตั้งค่าระบบ ดูประวัติการตั้งค่า และแก้กฎ SLA


=====================================================================
10. การโอนงาน ผู้ร่วมซ่อม และบันทึกความคืบหน้า
=====================================================================

10.1 โอนงานให้ช่างคนอื่น
    ผู้ทำได้        : ช่างผู้รับผิดชอบปัจจุบัน หรือผู้ดูแลระบบ
    สถานะที่โอนได้ : รับงานซ่อม, กำลังดำเนินงาน, สั่งซื้ออะไหล่,
                    แจ้งส่งซ่อมภายนอก, อะไหล่ถึงคลัง, รับเครื่องคืนแล้ว,
                    ช่างตรวจซ้ำ
    ขั้นตอน         : กด "โอนงานให้ช่างคนอื่น" -> เลือกช่างที่มีสิทธิ์
                    ประเภทนั้น -> ใส่เหตุผล (ไม่บังคับ) -> ยืนยัน
    ผลลัพธ์         : ชื่อผู้รับผิดชอบเปลี่ยนทันที ผู้โอนหลุดจากงาน
                    และระบบแจ้งเตือนผู้แจ้ง ผู้รับโอน และผู้ติดตาม
    ข้อจำกัด        : ช่างที่รับโอนต้องมีสิทธิ์ประเภทนั้น และไม่ใช่ผู้รับผิดชอบเดิม

10.2 ผู้ร่วมซ่อม (Co-technician)
    - เพิ่ม: ทำได้โดยช่างผู้รับผิดชอบหรือผู้ดูแลระบบ
    - นำออก: ช่างผู้รับผิดชอบ ผู้ดูแลระบบ หรือผู้ร่วมซ่อมคนนั้นเอง
    - ช่างที่เพิ่มต้องมีสิทธิ์ประเภทนั้น และต้องไม่ใช่ผู้รับผิดชอบหลัก
    - ผู้ร่วมซ่อมบันทึกความคืบหน้าได้
    - การเปลี่ยนสถานะทำได้โดยผู้มีสิทธิ์ช่างของประเภทนั้น
      (ไม่จำกัดเฉพาะผู้รับผิดชอบ) แต่การโอนงาน/จัดการผู้ร่วมซ่อม
      จำกัดเฉพาะผู้รับผิดชอบหรือผู้ดูแลระบบ
    - เพิ่มได้ในสถานะ: รับงานซ่อม, กำลังดำเนินงาน, สั่งซื้ออะไหล่,
      แจ้งส่งซ่อมภายนอก, อะไหล่ถึงคลัง, รับเครื่องคืนแล้ว, ช่างตรวจซ้ำ

10.3 บันทึกความคืบหน้า
    - ทำได้เฉพาะตอนสถานะ "กำลังดำเนินงาน"
    - ผู้ทำได้: ผู้รับผิดชอบ ผู้ร่วมซ่อม หรือผู้ดูแลระบบ
    - พิมพ์รายละเอียด (บังคับ) แล้วกด "บันทึกความคืบหน้า"
    - บันทึกได้หลายครั้ง แสดงใน Timeline พร้อมชื่อผู้บันทึกและเวลา


=====================================================================
11. ไฟล์แนบ (รูปและเอกสาร)
=====================================================================

11.1 ชนิดไฟล์ที่รับ
    - รูป: JPG, PNG, WEBP, HEIC
    - เอกสาร: PDF
    - HEIC เปิดได้เฉพาะเบราว์เซอร์ที่รองรับ (เช่น Safari)
      ถ้าเบราว์เซอร์อื่นไม่รองรับ ให้แปลงเป็น JPG ก่อน

11.2 ขนาดและจำนวน (ค่าเริ่มต้น ปรับได้ในหน้าตั้งค่า)
    - รูปสูงสุด 15 MB
    - PDF สูงสุด 10 MB
    - ไม่เกิน 30 ไฟล์ต่อใบซ่อม

11.3 การจัดการไฟล์
    - หน้าเว็บย่อรูปก่อนส่ง (ด้านยาวไม่เกิน 1920 px แปลงเป็น WebP
      และลบ EXIF/GPS) ไม่เก็บไฟล์ต้นฉบับ
    - ระบบตรวจชนิดไฟล์จากเนื้อไฟล์จริง และตรวจขนาด จำนวน และไฟล์ซ้ำ
    - ไม่รับ PDF ที่มีรหัสผ่านหรือมีสคริปต์ฝังอยู่
    - ใบที่ปิด ยกเลิก หรือรอจำหน่ายแล้ว แนบไฟล์เพิ่มไม่ได้และลบไฟล์ไม่ได้
    - ไฟล์ที่ใช้ยืนยันการเปลี่ยนสถานะแล้ว หรือรูปอะไหล่ ลบไม่ได้

11.4 ไฟล์ที่บังคับ
    - สั่งซื้ออะไหล่: รูปอย่างน้อย 1 รูปต่อรายการอะไหล่
    - ซ่อมเสร็จ: รูปผลการซ่อม "ไม่บังคับ" (แนะนำให้แนบ)
    - ขั้นอื่น ๆ รวมถึงการแนบเอกสาร PO: ไม่บังคับ


=====================================================================
12. การอนุมัติ PO และการอนุมัติราคาซ่อมภายนอก
=====================================================================

12.1 การอนุมัติ PO (อะไหล่)

  ช่างสั่งซื้ออะไหล่
    -> พัสดุรับเรื่องอะไหล่
    -> พัสดุกรอกเลข PO และส่งขออนุมัติ (PO_PENDING)
    -> ผู้อนุมัติ PO พิจารณา
         อนุมัติ        -> ได้รับการอนุมัติ PO แล้ว -> เริ่มจัดซื้อ
                           -> อะไหล่ถึงคลัง -> ช่างรับอะไหล่และซ่อมต่อ
         ไม่อนุมัติ + เหตุผล -> กลับไปพัสดุรับเรื่องอะไหล่
                           -> พัสดุแก้ไขแล้วส่งขออนุมัติใหม่

12.2 การอนุมัติราคาซ่อมภายนอก

  ช่างแจ้งส่งซ่อมภายนอก
    -> พัสดุรับเรื่อง
    -> พัสดุเลือกร้าน + กรอกราคาที่ร้านเสนอ (EXT_PRICE_PENDING)
    -> ผู้อนุมัติ PO พิจารณา
         อนุมัติ        -> อนุมัติราคาแล้ว รอส่งซ่อม (EXT_PRICE_APPROVED)
                           -> พัสดุส่งร้าน + วันที่ส่ง
                           -> พัสดุรับเครื่องคืน + ค่าซ่อมจริง
                           -> ช่างตรวจรับและซ่อมต่อ
         ไม่อนุมัติ + เหตุผล -> กลับไปขั้นพัสดุ (EXT_APPROVAL)
                           -> พัสดุเทียบราคาใหม่แล้วส่งขออนุมัติอีกครั้ง

  ระบบบันทึกผู้อนุมัติ เวลาที่อนุมัติ และเหตุผลกรณีไม่อนุมัติ
  ไว้ในข้อมูลส่งซ่อมภายนอกของใบซ่อม


=====================================================================
13. ประวัติการซ่อม ประวัติการทำงาน และประวัติการยื่น PO
=====================================================================

13.1 ประวัติการซ่อม
    มี 2 ส่วน

  ก. ตารางใบซ่อมทั้งหมด
    - ด้านบนมีช่อง "ดูสรุปรายเครื่อง" (ค้นหารหัส/ชื่อแล้วเลือกเครื่อง)
    - แสดงใบซ่อมที่ผู้ใช้มีสิทธิ์เห็น ทั้งที่มีและไม่มีรหัสครุภัณฑ์
    - คอลัมน์: เลขใบซ่อม, วันที่แจ้ง, ครุภัณฑ์ / สิ่งของ, อาการ,
      สถานะ, ผลการซ่อม, ค่าใช้จ่าย, คะแนน
    - ผู้แจ้งซ่อมเห็นเฉพาะใบของตนเอง
    - ตัวกรองประเภท (เรียงลำดับ):
        ทุกประเภท -> ทั่วไป -> คอมพิวเตอร์ -> เครื่องมือแพทย์
    - ตัวกรอง มี/ไม่มีรหัสครุภัณฑ์
    - ค้นหาจากเลขใบ ชื่อ อาการ หรือแผนก
    - แสดง 30 ใบต่อหน้า พร้อมปุ่ม ก่อนหน้า / ถัดไป

  ข. สถิติการซ่อมรายครุภัณฑ์
    - ไม่แสดงข้อมูลทันทีเมื่อเปิดหน้า ต้องกดปุ่ม "แสดงสถิติ" ก่อน
      (กด "ซ่อนสถิติ" เพื่อปิด)
    - นับทุกใบซ่อมของเครื่อง รวมใบที่ยกเลิก
    - คอลัมน์: รหัสครุภัณฑ์, ชื่อ/แผนก, ประเภท, ซ่อมทั้งหมด,
      ใน 12 เดือน, ยกเลิก, ค่าซ่อมสะสม, ซ่อมล่าสุด
    - กดแถวเพื่อดูสรุปของเครื่องนั้น (หน้า /assets/:id) ซึ่งแสดง
      ข้อมูลเครื่อง สถานะในทะเบียน ราคาซื้อ ประวัติทั้งหมด
      วันที่ใช้งานไม่ได้ วันเฉลี่ยระหว่างการเสีย (MTBF)
      ค่าซ่อมสะสม และคำแนะนำให้จำหน่าย
    - คำแนะนำให้จำหน่ายแสดงเมื่อเครื่องถูกซ่อมครบ 4 ครั้งใน 12 เดือน
      (ปรับจำนวนครั้งได้ที่ค่าตั้งระบบ replace_suggest_count_12m)
    - ค่าใช้จ่ายต่อใบ = ราคาอะไหล่จริง (ถ้าไม่มีใช้ราคาประมาณ)
      + ค่าซ่อมภายนอกจริง
    - หน้ารายเครื่องไม่แบ่งหน้า แสดงใบซ่อมทั้งหมดของเครื่องนั้น
      (กด "ทุกใบซ่อม" เพื่อกลับไปหน้ารวม)

13.2 ประวัติการทำงาน (เมนู "ประวัติการทำงาน")
    - สำหรับช่าง และพัสดุ (และผู้ดูแลระบบ)
    - แสดงใบซ่อมที่ตนเป็นช่างผู้รับผิดชอบ เป็นผู้ร่วมซ่อม
      หรือเป็นผู้เปลี่ยนสถานะ
    - กดเลขใบซ่อมเพื่อดูขั้นตอนการซ่อมของใบนั้น
    - ค้นหาจากเลขใบ ชื่อสิ่งของ อาการ หรือรหัสครุภัณฑ์
    - ตารางแสดงเลขใบซ่อม วันที่แจ้ง ครุภัณฑ์ / สิ่งของ อาการ สถานะ
      ผลการซ่อม ค่าใช้จ่าย และคะแนน
    - แบ่งหน้า 30 ใบ พร้อมปุ่ม ก่อนหน้า / ถัดไป และแสดงจำนวนใบทั้งหมด

13.3 ประวัติการยื่น PO (เมนู "ประวัติการยื่น PO")
    - สำหรับพัสดุ และผู้ดูแลระบบ
    - พัสดุเห็นเฉพาะ PO ที่ตนเองยื่น (ผู้ดูแลระบบเห็นทั้งหมด)
    - คอลัมน์: เลขที่ PO, วันที่ PO, ใบซ่อม, ครุภัณฑ์ / สิ่งของ,
      สถานะ PO, ผู้อนุมัติ, วันที่ยื่น
    - สถานะ PO: รออนุมัติ / อนุมัติแล้ว / ไม่อนุมัติ
      (แสดงเหตุผลกรณีไม่อนุมัติ)
    - ค้นหาจากเลขที่ PO เลขใบซ่อม หรือชื่อสิ่งของ
    - แบ่งหน้า 30 รายการ พร้อมปุ่ม ก่อนหน้า / ถัดไป
    - กดแถวเพื่อเปิดใบซ่อมที่เกี่ยวข้อง

14. ประวัติการตั้งค่า (Audit Log)
=====================================================================

    - เห็นได้เฉพาะผู้มีสิทธิ์ "ดูประวัติการแก้ไข" (repair.audit.view)
    - บันทึกการเปลี่ยนแปลงข้อมูลสำคัญ เช่น ค่าตั้งระบบ กฎ SLA
      ราคาอะไหล่ ค่าซ่อมภายนอก ผลอนุมัติ PO และสถานะครุภัณฑ์
    - ตัวกรองหมวดในหน้าเว็บมี 3 กลุ่ม: ค่าตั้งระบบ,
      เวลาที่กำหนด (SLA), สถานะครุภัณฑ์
      (เลือก "ทั้งหมด" เพื่อดูทุกตาราง รวมราคาอะไหล่/PO/ซ่อมภายนอก)
    - กรองช่วงวันที่ (ค่าเริ่มต้นคือวันนี้ ล้างช่องวันที่เพื่อดูย้อนหลัง)
    - คอลัมน์: เวลา, ผู้แก้, รายการ (ตาราง/การกระทำ/รหัสเรกคอร์ด),
      ค่าเดิม → ค่าใหม่, เหตุผล
    - แสดงสูงสุด 500 รายการล่าสุดตามตัวกรอง
    - แถวที่แก้ไขตรงในฐานข้อมูล (ไม่มีผู้ใช้ในระบบ) จะแสดงสีแดง
      พร้อมชื่อผู้ใช้ฐานข้อมูล
    - ประวัติแก้ไขหรือลบไม่ได้

15. ตั้งค่าระบบ
=====================================================================

เฉพาะผู้ดูแลระบบ (admin) เท่านั้น:

    - เมนู "ตั้งค่าระบบ" แสดงเฉพาะผู้ดูแลระบบ (admin) เท่านั้น
    - หน้าแสดง 2 ส่วน: กฎ SLA (สถานะ + เวลาเตือน หน่วยชั่วโมง)
      และค่าตั้งทั่วไป (ขนาดไฟล์ จำนวนไฟล์ รอบตรวจงานค้าง
      เกณฑ์แนะนำจำหน่าย ฯลฯ)
    - แก้กฎ SLA ได้ทีละแถว เวลาเตือนต้องมากกว่า 0 ชั่วโมง
      (ช่องกรอกขั้นต่ำ 0.5 ชั่วโมง)
    - ทุกการแก้ไขต้องระบุเหตุผล (บังคับ) และถูกบันทึกในประวัติการตั้งค่า
    - ผู้ใช้ที่เข้าหน้านี้ได้แต่ไม่มีสิทธิ์แก้ไข จะเห็นแบบอ่านอย่างเดียว

16. การแจ้งเตือน และ SLA
=====================================================================

16.1 การแจ้งเตือน
    ระบบแจ้งเตือนเมื่อ:
    - มีใบซ่อมใหม่ (ถึงช่างที่มีสิทธิ์ประเภทนั้น)
    - มีการเปลี่ยนสถานะ (ถึงผู้แจ้ง ช่างผู้รับผิดชอบ และผู้ติดตาม)
    - มีการโอนงาน (ถึงผู้แจ้ง ผู้รับโอน และผู้ติดตาม)
    - มีผู้ติดตามเพิ่ม (ผู้แจ้งปัญหาเดียวกัน)
    - มีผู้ร่วมซ่อมเพิ่ม
    - ใบซ่อมถูกส่งให้พัสดุ (สั่งอะไหล่/ส่งซ่อมภายนอก)
      หรือผู้อนุมัติ PO (ขออนุมัติ PO/ราคาซ่อม)
    - งานค้างเกินกำหนด (SLA) ตามรอบตรวจงานค้าง

    ดูได้จากปุ่มรูประฆังมุมขวาบน (โหลดใหม่ทุก 1 นาที)
    รายการ SLA มีแถบแดงด้านซ้าย กดรายการเพื่อไปยังใบซ่อม
    เมื่อเปิดดูรายการ ระบบจะทำเครื่องหมายว่าอ่านแล้วทั้งหมด

    ระบบตรวจงานค้างตามรอบที่ตั้งไว้ และส่งแจ้งเตือนผู้เกี่ยวข้อง
    เมื่อเกินกำหนด (ครั้งเดียวต่อการเข้าสถานะนั้น)

16.2 ระยะเวลา SLA เริ่มต้น (แจ้งเตือนเมื่อค้างเกิน)

  สถานะ                                       เตือนเมื่อค้างเกิน
  ------------------------------------------  ------------------------
  แจ้งซ่อม (NEW)                              24 ชม. (วิกฤต: 2 ชม.)
  รับงานซ่อม (ACCEPTED)                       24 ชม.
  กำลังดำเนินงาน (IN_PROGRESS)                72 ชม.
  สั่งซื้ออะไหล่ / แจ้งส่งซ่อมภายนอก          24 ชม.
  พัสดุรับเรื่องอะไหล่ / รออนุมัติส่งซ่อม     72 ชม.
  รออนุมัติ PO                                72 ชม.
  ได้รับการอนุมัติ PO แล้ว                    24 ชม.
  อะไหล่ถึงคลัง / รับอุปกรณ์คืนแล้ว           24 ชม.
  ส่งร้านภายนอกแล้ว                           336 ชม. (14 วัน)
  รอตรวจรับ (DONE)                            72 ชม.

  สถานะที่ยังไม่มีกฎ SLA เริ่มต้น: กำลังจัดซื้ออะไหล่,
  รออนุมัติราคาซ่อมภายนอก, อนุมัติราคาแล้ว รอส่งซ่อม,
  ช่างตรวจซ้ำ, รอจำหน่าย (และสถานะสิ้นสุด)
  ผู้ดูแลระบบเพิ่มกฎได้ที่เมนูตั้งค่าระบบ

  ระบบเลือกกฎที่เฉพาะเจาะจงที่สุดก่อน: ถ้ามีกฎแยกตามความเร่งด่วน
  หรือประเภทงาน จะใช้กฎนั้นแทนกฎทั่วไปของสถานะ

16.3 ตัวบ่งชี้ SLA
    ปกติ: ยังไม่ถึง 80% ของเวลาเตือน
    ใกล้ครบ: ตั้งแต่ 80% ของเวลาเตือน
    เกินกำหนด: ถึงหรือเกินเวลาเตือนแล้ว

17. คำถามที่พบบ่อย
=====================================================================

Q: ทำไมไม่เห็นใบซ่อมบางใบ?
A: ระบบแสดงเฉพาะประเภทที่คุณมีสิทธิ์ แต่ใบซ่อมที่คุณแจ้งเองจะเห็นเสมอ
   ในหน้าประวัติการซ่อม ผู้แจ้งซ่อมจะเห็นเฉพาะใบของตนเอง
   ส่วนหน้ารายการ แท็บ "แจ้งซ่อมของฉัน" แสดงเฉพาะใบของตนเอง
   และแท็บอื่นแสดงใบของทุกคนในประเภทที่คุณมีสิทธิ์
   ติดต่อผู้ดูแลระบบหากต้องการสิทธิ์เพิ่ม

Q: แจ้งซ่อมแล้วขึ้นว่ามีใบซ่อมค้างอยู่?
A: เครื่องนี้มีใบที่ยังไม่ปิด ให้เลือก "ติดตามใบเดิม" หรือถ้าอาการต่างกัน
   ให้เลือก "แจ้งใหม่" และกรอกเหตุผล

Q: ทำไมบันทึกความคืบหน้าไม่ได้?
A: ต้องอยู่ในสถานะกำลังดำเนินงาน และคุณต้องเป็นผู้รับผิดชอบหรือผู้ร่วมซ่อม

Q: ทำไมเริ่มงาน (เริ่มดำเนินงาน) ไม่ได้?
A: ต้องกรอก "ระยะเวลาที่คาดไว้ในการซ่อม (จำนวนวัน)" ตั้งแต่ 1 วันขึ้นไป
   ก่อนทุกครั้ง

Q: ทำไมส่งซ่อมภายนอกต่อไม่ได้?
A: ต้องรอผู้อนุมัติ PO อนุมัติราคาที่ร้านเสนอก่อน จึงจะส่งร้านได้
   (สถานะ "อนุมัติราคาแล้ว รอส่งซ่อม")

Q: ราคาที่ร้านเสนอถูกไม่อนุมัติ ต้องทำอย่างไร?
A: ใบจะกลับไปที่พัสดุสถานะ "รออนุมัติส่งซ่อม" พร้อมเหตุผล
   ให้เจรจา/เทียบราคาใหม่ แล้วส่งขออนุมัติอีกครั้ง

Q: ปุ่ม "เปลี่ยนประเภทครุภัณฑ์" หายไป?
A: ปุ่มนี้แสดงเฉพาะช่างผู้รับผิดชอบ และเฉพาะสถานะรับงานซ่อม
   หรือกำลังดำเนินงาน

Q: ส่งรอจำหน่ายแล้วแก้ไขต่อได้ไหม?
A: ไม่ได้ สถานะรอจำหน่าย (DISPOSAL) เป็นสถานะสิ้นสุด ระบบปิดใบซ่อม
   และปรับทะเบียนครุภัณฑ์เป็น "รอจำหน่าย"

Q: ทำไมเปลี่ยนสถานะไม่ได้?
A: ตรวจว่าข้อมูลบังคับครบ (เช่น เหตุผล รูปอะไหล่ เลข PO ราคาที่ร้านเสนอ
   ค่าซ่อม ระยะเวลาที่คาดไว้ วันที่) และตรวจว่าคุณมีบทบาทที่ทำขั้นนั้นได้

Q: ทำไมโอนงานให้ช่างบางคนไม่ได้?
A: ช่างที่รับโอนต้องมีสิทธิ์ประเภทของใบนั้น และใบต้องอยู่ในสถานะที่โอนได้

Q: วันที่ในฟอร์มเป็นอะไร?
A: ค่าเริ่มต้นเป็นวันปัจจุบัน และเลือกวันในอนาคตไม่ได้

Q: ทำไมหน้ารายการแจ้งซ่อมจากเมนูประเภทไม่เปลี่ยนประเภท?
A: ประเภทจะถูกล็อกตามเมนูที่เลือก เพื่อเปลี่ยนประเภทให้เลือกจากเมนู Sidebar

Q: ทำไมหน้าประวัติการซ่อมไม่มีข้อมูลสถิติ?
A: สถิติโหลดเมื่อกดปุ่ม "แสดงสถิติ" เท่านั้น

Q: ซ่อมเสร็จต้องแนบรูปผลการซ่อมไหม?
A: ไม่บังคับ แต่แนะนำให้แนบรูปผลการซ่อมเพื่อเป็นหลักฐาน
   (ระบบบังคับเฉพาะรูปของแต่ละรายการอะไหล่)

Q: ทำไมไม่เห็นแท็บ "รออนุมัติ PO / ราคาซ่อม"?
A: แท็บนี้แสดงเฉพาะผู้ใช้ที่มีบทบาทผู้อนุมัติ PO เพียงอย่างเดียว
   ถ้ามีหลายบทบาท ให้ค้นใบที่รออนุมัติจากแท็บ "งานที่ยังไม่ปิด"
   หรือ "ทั้งหมด" (แท็บงานพัสดุก็แสดงใบที่รออนุมัติได้)

Q: ทำไมไม่เห็นแท็บ "แจ้งซ่อมของฉัน" หรือ "รอตรวจรับ"?
A: สองแท็บนี้แสดงเมื่อคุณมีสิทธิ์แจ้งซ่อมของประเภทนั้น ๆ
   ถ้าเป็นช่างอย่างเดียวจะไม่เห็น ให้ติดต่อผู้ดูแลระบบหากต้องการสิทธิ์แจ้งซ่อม

Q: ผู้แจ้งซ่อมกด "เปิดงานอีกครั้ง" ได้ไหม?
A: ไม่ได้ การเปิดงานที่ปิดแล้วทำได้เฉพาะช่างผู้มีสิทธิ์ประเภทนั้น
   หรือผู้ดูแลระบบ หากต้องการซ่อมต่อให้แจ้งช่างหรือผู้ดูแลระบบ

Q: "เปิดซ้ำ N ครั้ง" ที่หัวใบซ่อมหมายถึงอะไร?
A: จำนวนครั้งที่ใบนี้ถูกเปิดงานอีกครั้งหลังปิดงานแล้ว
   (ไม่แสดงเมื่อยังไม่เคยเปิดซ้ำ)

Q: เปลี่ยนรหัสผ่านได้ที่ไหน?
A: ที่หน้า Hub กดปุ่ม "เปลี่ยนรหัส" มุมขวาบน แล้วกรอกรหัสผ่านปัจจุบัน
   รหัสผ่านใหม่ (อย่างน้อย 4 ตัวอักษร) และยืนยันรหัสผ่านใหม่


=====================================================================
18. ข้อควรทราบสำหรับการใช้งาน
=====================================================================

    - ขั้นอนุมัติ PO และการอนุมัติราคาซ่อมภายนอก เป็นการอนุมัติขั้นเดียว
      โดยผู้อนุมัติ PO (po_approver) ไม่ใช่พัสดุกดข้ามขั้นเอง
      และไม่มีการอนุมัติหลายระดับในระบบ
    - การเปลี่ยนสถานะคิดตามสิทธิ์ประเภทงานของผู้ใช้ ไม่ผูกกับ
      "งานที่ฉันรับผิดชอบ" (แท็บนั้นเป็นเพียงตัวกรองรายการ)
      แต่การโอนงาน/เปลี่ยนครุภัณฑ์/จัดการผู้ร่วมซ่อมจำกัดเฉพาะ
      ช่างผู้รับผิดชอบหรือผู้ดูแลระบบ
    - ใบซ่อมที่ปิด ยกเลิก หรือรอจำหน่ายแล้วจะแนบหรือลบไฟล์ไม่ได้
      (รูปของรายการอะไหล่และไฟล์ยืนยันการเปลี่ยนสถานะลบไม่ได้)
    - ยังไม่รองรับใบเสนอราคาในระบบ ให้แนบเอกสารเป็นไฟล์ไว้ที่ใบซ่อมแทน
    - หากพบปัญหาการใช้งาน ให้แจ้งผู้ดูแลระบบพร้อมเลขใบซ่อม (RP-YYNNNN)
      และขั้นตอนที่ทำก่อนเกิดปัญหา
