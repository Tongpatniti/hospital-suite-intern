=====================================================================
คู่มือการใช้งานระบบแจ้งซ่อม (Repair System User Guide)
=====================================================================

คู่มือนี้อธิบายการใช้งานระบบแจ้งซ่อมในการทำงานจริง ทุกส่วนและทุกบทบาท
อ้างอิงจากการทำงานของโปรแกรม (หน้าเว็บ repair-app และ API backend)

สารบัญ
---------------------------------------------------------------------
 1. ภาพรวมระบบ
 2. บทบาทและสิทธิ์การใช้งาน
 3. บัญชีผู้ใช้และการขอสิทธิ์
 4. การเข้าสู่ระบบ และเมนู Sidebar
 5. การแจ้งซ่อม (สร้างใบซ่อมใหม่)
 6. หน้ารายการแจ้งซ่อม
 7. หน้ารายละเอียดใบซ่อม
 8. สถานะของใบซ่อมและผู้ที่เปลี่ยนได้
 9. ขั้นตอนการทำงานของแต่ละบทบาท
10. การโอนงาน ผู้ร่วมซ่อม และบันทึกความคืบหน้า
11. ไฟล์แนบ (รูปและเอกสาร)
12. การอนุมัติ PO
13. ประวัติการซ่อม
14. ประวัติการตั้งค่า (Audit Log)
15. ตั้งค่าระบบ
16. การแจ้งเตือน และ SLA
17. คำถามที่พบบ่อย
18. ข้อควรทราบสำหรับการใช้งาน


=====================================================================
1. ภาพรวมระบบ
=====================================================================

ระบบแจ้งซ่อมใช้แจ้งซ่อมและติดตามงานซ่อมของครุภัณฑ์ มี 3 ประเภทงาน:

  - คอมพิวเตอร์ (COMPUTER)        เช่น เครื่องคอมพิวเตอร์ จอภาพ เครื่องพิมพ์
  - เครื่องมือแพทย์ (MEDICAL)     เช่น Infusion pump, เครื่องวัดความดัน
  - ทั่วไป (GENERAL)              เช่น เครื่องปรับอากาศ ระบบไฟฟ้า เฟอร์นิเจอร์

แต่ละใบซ่อมมีเลขที่รูปแบบ RP-YYNNNN (เช่น RP-690001) และเคลื่อนผ่านหลายสถานะ
ตั้งแต่ "แจ้งซ่อม" จนถึง "ปิดงาน" หรือ "ยกเลิก"

ทุกการเปลี่ยนสถานะ การโอนงาน การแก้ไขข้อมูลสำคัญ และการแจ้งเตือน
จะถูกบันทึกไว้เป็นประวัติ


=====================================================================
2. บทบาทและสิทธิ์การใช้งาน
=====================================================================

ผู้ใช้หนึ่งคนอาจมีได้หลายบทบาท สิทธิ์กำหนดโดยผู้ดูแลระบบ

2.1 ผู้แจ้งซ่อม (Requester)
    - แจ้งซ่อมประเภทที่ได้รับสิทธิ์
    - ติดตามใบซ่อมของตนเองและใบที่ติดตาม
    - ตรวจรับงานซ่อม ให้คะแนน 1-5 ดาว หรือส่งกลับซ่อม
    - ยกเลิกใบซ่อมตามสถานะที่กำหนด (ต้องระบุเหตุผล)
    - เปิดงานอีกครั้งหลังปิดงานแล้ว

2.2 ช่างซ่อม (Technician) แยกตามประเภท
    - รับงาน / เริ่มดำเนินงาน
    - สั่งซื้ออะไหล่ / ส่งซ่อมภายนอก
    - รับอะไหล่แล้วซ่อมต่อ / ตรวจรับเครื่องจากร้านแล้วซ่อมต่อ
    - แจ้งซ่อมเสร็จ (ระบุผลการซ่อม และแนบรูปผลการซ่อม)
    - โอนงานให้ช่างคนอื่นที่มีสิทธิ์ประเภทเดียวกัน
    - เพิ่ม / นำผู้ร่วมซ่อมออก (เฉพาะช่างผู้รับผิดชอบ)
    - บันทึกความคืบหน้า (เฉพาะสถานะกำลังดำเนินงาน)
    - ช่างคอมพิวเตอร์จะไม่เห็นงานเครื่องมือแพทย์ และในทางกลับกัน
      ยกเว้นมีสิทธิ์ของทั้งสองประเภท

2.3 พัสดุ (Supply)
    - รับเรื่องอะไหล่ และส่งขออนุมัติ PO (กรอกเลข PO)
    - เริ่มจัดซื้อ / บันทึกอะไหล่ถึงคลัง / บันทึกราคาจริงของอะไหล่
    - รับเรื่องส่งซ่อมภายนอก / ส่งร้าน / รับเครื่องคืน (กรอกค่าซ่อม)
    - เห็นงานทุกประเภท

2.4 ผู้อนุมัติ PO (PO Approver)
    - เห็นเฉพาะใบที่รออนุมัติ PO
    - อนุมัติ PO หรือไม่อนุมัติ (ต้องระบุเหตุผล)
    - เห็นงานทุกประเภท

2.5 ผู้ดูแลระบบ (Admin)
    - เห็นทุกใบซ่อม ทุกสถานะ และทุกประเภท
    - ทำได้ทุกขั้นตอนตามสิทธิ์ของระบบ
    - ตั้งค่าระบบและกฎ SLA
    - ดูประวัติการตั้งค่า (Audit Log)

หมายเหตุ: ผู้ใช้จะเห็นเฉพาะใบซ่อมของประเภทที่ตนมีสิทธิ์ ยกเว้นพัสดุ
ผู้อนุมัติ PO และผู้ดูแลระบบ ซึ่งเห็นทุกประเภท


=====================================================================
3. บัญชีผู้ใช้และการขอสิทธิ์
=====================================================================

3.1 การได้รับบัญชี
    - ผู้ดูแลระบบของหน่วยงานเป็นผู้สร้างบัญชีและกำหนดสิทธิ์ให้
    - ติดต่อผู้ดูแลระบบเพื่อขอ Username และรหัสผ่านเริ่มต้น
    - ขอให้ผู้ดูแลระบบเปลี่ยนรหัสผ่านเริ่มต้นให้เป็นของคุณ
    - ห้ามแชร์บัญชีกับผู้อื่น ทุกการดำเนินการจะถูกบันทึกภายใต้ชื่อผู้ใช้

3.2 การขอสิทธิ์เพิ่มหรือเปลี่ยนบทบาท
    - ติดต่อผู้ดูแลระบบพร้อมระบุ ชื่อ แผนก ประเภทงานที่ต้องดูแล
      และบทบาทที่ต้องการ (แจ้งซ่อม / ช่าง / พัสดุ / ผู้อนุมัติ PO)
    - ไม่มีสิทธิ์ที่ตรงกับงาน ให้แจ้งผู้ดูแลระบบให้ตรวจสอบ


=====================================================================
4. การเข้าสู่ระบบ และเมนู Sidebar
=====================================================================

4.1 การเข้าสู่ระบบ
    1) เปิดหน้าเว็บระบบแจ้งซ่อม
    2) กรอก Username และ Password แล้วกดเข้าสู่ระบบ
    3) หรือเข้าจากหน้า Hub ระบบจะเข้าสู่ระบบให้อัตโนมัติ

4.2 เมนู Sidebar (แสดงตามสิทธิ์ของผู้ใช้)

    [รายการแจ้งซ่อม]                 หน้ารายการใบซ่อมทั้งหมด (ทุกประเภท)
    [Back to Hub]                    กลับไปหน้า Hub
    กลุ่ม "แจ้งซ่อม"                 แจ้งซ่อมทั่วไป / คอมพิวเตอร์ / เครื่องมือแพทย์
                                     (เห็นเฉพาะประเภทที่มีสิทธิ์แจ้ง)
    กลุ่ม "รายการการแจ้งซ่อม"         รายการใบซ่อมแยกตามประเภท
                                     (เห็นเฉพาะประเภทที่มีสิทธิ์ดู)
    ประวัติการซ่อม                   ประวัติและสถิติการซ่อม
    ประวัติการตั้งค่า                 Audit Log (เฉพาะผู้มีสิทธิ์)
    ตั้งค่าระบบ                      ค่าตั้งระบบและกฎ SLA (เฉพาะผู้มีสิทธิ์)

    ไอคอนประเภท: ทั่วไป, คอมพิวเตอร์, เครื่องมือแพทย์

4.3 การแจ้งเตือน
    มุมขวาบนมีปุ่มรูประฆัง แสดงจำนวนที่ยังไม่ได้อ่าน
    กดรายการเพื่อไปยังใบซ่อมนั้น


=====================================================================
5. การแจ้งซ่อม (สร้างใบซ่อมใหม่)
=====================================================================

5.1 ขั้นตอน
    1) เลือกเมนู "แจ้งซ่อม" แล้วเลือกประเภท (เช่น แจ้งซ่อมคอมพิวเตอร์)
    2) เลือกครุภัณฑ์
       - ค้นหาด้วยรหัสหรือชื่อ แล้วเลือกจากรายการ
       - หรือติ๊ก "ไม่มีรหัสครุภัณฑ์" แล้วกรอกชื่อสิ่งของ (บังคับ)
    3) ระบบตรวจว่าเครื่องนี้มีใบซ่อมที่ยังไม่ปิดอยู่หรือไม่
       - ถ้ามี เลือก "ติดตามใบเดิม" หรือ "แจ้งใหม่ (อาการต่างกัน)"
         โดยการแจ้งใหม่ต้องกรอกเหตุผล
    4) เลือกความเร่งด่วน: ต่ำ / ปกติ / สูง / วิกฤต
    5) กรอกสถานที่ตั้ง (ระบบเติมให้จากครุภัณฑ์ได้)
    6) กรอกอาการเสีย (บังคับ)
    7) แนบรูปอาการเสียหรือเอกสาร (ไม่บังคับ)
    8) กด "ส่งใบแจ้งซ่อม"

    ผลลัพธ์: ได้เลขใบซ่อม RP-YYNNNN ใบอยู่สถานะ "แจ้งซ่อม"
    และแจ้งเตือนช่างที่มีสิทธิ์ประเภทนั้นทันที

5.2 การติดตามใบเดิม
    ใบที่ผู้ใช้เลือก "ติดตามใบเดิม" จะเพิ่มผู้ใช้เป็นผู้ติดตาม
    ไม่ได้สร้างใบซ่อมใหม่ ผู้ติดตามจะได้รับการแจ้งเตือนความคืบหน้า
    ผู้ติดตามเลิกติดตามได้จากหน้ารายละเอียดใบซ่อม


=====================================================================
6. หน้ารายการแจ้งซ่อม
=====================================================================

6.1 แท็บตามบทบาท
    ผู้แจ้งซ่อม : แจ้งซ่อมของฉัน, รอช่างรับงาน, รอตรวจรับ,
                  รายการที่เสร็จสิ้น, ยกเลิก/ปฏิเสธ, ทั้งหมด
    ช่าง       : งานที่ฉันรับผิดชอบ, รอช่างรับงาน, งานที่ยังไม่ปิด,
                  รายการที่เสร็จสิ้น, ยกเลิก/ปฏิเสธ, ทั้งหมด
    พัสดุ      : งานพัสดุ, งานที่ฉันดำเนินการ, รอช่างรับงาน,
                  งานที่ยังไม่ปิด, รายการที่เสร็จสิ้น, ยกเลิก/ปฏิเสธ, ทั้งหมด
    ผู้อนุมัติ PO: รออนุมัติ PO (แท็บเดียว)
    ผู้ดูแลระบบ : งานที่ยังไม่ปิด, รอรับงาน, รอตรวจรับ, งานพัสดุ,
                  ยกเลิก/ปฏิเสธ, ทั้งหมด

6.2 การกรองและค้นหา
    - ประเภทงาน: หน้ารายการที่เปิดจากเมนูประเภท จะแสดงเฉพาะประเภทนั้น
      หน้ารายการจากเมนู "รายการแจ้งซ่อม" จะแสดงทุกประเภท
      ตัวเลือกประเภทถูกล็อกไว้ทั้งสองกรณี
    - ช่องค้นหา: ค้นจากเลขใบซ่อม ชื่อ หรือรหัสครุภัณฑ์
    - ปุ่มสลับมุมมอง:
        "จัดลำดับ: ของฉันก่อน"       (ค่าเริ่มต้น)
        "แสดงทั้งหมด (ไม่จัดลำดับของฉันก่อน)"

6.3 การเรียงลำดับ
    กดที่หัวตาราง (เลขใบซ่อม / สถานะ / SLA / แจ้งเมื่อ)
    - กดครั้งแรก: มากไปน้อย (▼)
    - กดอีกครั้ง: น้อยไปมาก (▲)

6.4 สัญลักษณ์ SLA
    เขียว    ปกติ ยังไม่ถึงกำหนด
    เหลือง   ใกล้ครบกำหนด (ถึง 80% ของเวลาที่กำหนด)
    แดง      ครบหรือเกินกำหนดแล้ว

    กดที่แถวใดก็ได้เพื่อเปิดหน้ารายละเอียดใบซ่อม


=====================================================================
7. หน้ารายละเอียดใบซ่อม
=====================================================================

ส่วนประกอบของหน้า
    หัวใบซ่อม          เลขใบซ่อม ชื่อเรื่อง สถานะ ประเภท ความเร่งด่วน
    ปุ่มดำเนินการ      ปุ่มติดตาม/เลิกติดตาม, โอนงาน (เฉพาะช่างผู้รับผิดชอบ/
                       ผู้ดูแลระบบ), และปุ่มสถานะถัดไปตามสิทธิ์
    Timeline           ประวัติการเปลี่ยนสถานะและการแจ้งเตือน SLA
    ความคืบหน้าการซ่อม บันทึกความคืบหน้า (เฉพาะสถานะกำลังดำเนินงาน)
    ผู้ร่วมซ่อม        รายชื่อผู้ร่วมซ่อม
    รายการอะไหล่        อะไหล่ที่ขอซื้อ และราคาจริง
    ใบสั่งซื้อ (PO)    เลข PO สถานะ และผู้อนุมัติ
    ส่งซ่อมภายนอก     ร้าน วันที่ส่ง/รับคืน ค่าซ่อม
    ไฟล์แนบ            รูปและเอกสาร
    ข้อมูลครุภัณฑ์    ข้อมูล ณ วันที่แจ้ง รวมผู้ซ่อมเสร็จและผู้ปิดงาน
    ผู้ติดตาม          ผู้ที่ติดตามใบนี้
    ซ่อมครั้งก่อน      ใบซ่อมก่อนหน้าของครุภัณฑ์เดียวกัน


=====================================================================
8. สถานะของใบซ่อม
=====================================================================

8.1 รายชื่อสถานะ

  รหัส              ชื่อที่แสดง                       ผู้รับผิดชอบขั้นนี้
  ----------------  --------------------------------  -----------------
  NEW               แจ้งซ่อม                          ช่าง
  ACCEPTED          รับงานซ่อม                        ช่าง
  IN_PROGRESS       กำลังดำเนินงาน                    ช่าง
  WAIT_PART         สั่งซื้ออะไหล่                    พัสดุ
  PART_APPROVAL     พัสดุรับเรื่องอะไหล่              พัสดุ
  PO_PENDING        รออนุมัติ PO                      ผู้อนุมัติ PO
  PO_APPROVED       ได้รับการอนุมัติ PO แล้ว          พัสดุ
  PART_PURCHASING   กำลังจัดซื้ออะไหล่                 พัสดุ
  PART_ARRIVED      อะไหล่ถึงคลัง                     ช่าง
  WAIT_EXTERNAL     แจ้งส่งซ่อมภายนอก                 พัสดุ
  EXT_APPROVAL      รออนุมัติส่งซ่อม                  พัสดุ
  EXT_SENT          ส่งร้านภายนอกแล้ว                 พัสดุ
  EXT_RECEIVED      รับอุปกรณ์คืนแล้ว                 ช่าง
  DONE              รอตรวจรับ                         ผู้แจ้งซ่อม
  CLOSED            ปิดงาน                            ผู้แจ้งซ่อม
  CANCELLED         ยกเลิก                            ผู้มีสิทธิ์ยกเลิก

8.2 การเปลี่ยนสถานะที่อนุญาต

  จาก                    ไปยัง (ที่อนุญาต)
  ---------------------  ----------------------------------------------
  NEW                    ACCEPTED, CANCELLED
  ACCEPTED               IN_PROGRESS, CANCELLED
  IN_PROGRESS            DONE, WAIT_PART, WAIT_EXTERNAL, CANCELLED
  WAIT_PART              PART_APPROVAL, CANCELLED
  PART_APPROVAL          PO_PENDING, CANCELLED
  PO_PENDING             PO_APPROVED, PART_APPROVAL (ไม่อนุมัติ)
  PO_APPROVED            PART_PURCHASING
  PART_PURCHASING        PART_ARRIVED
  PART_ARRIVED           IN_PROGRESS
  WAIT_EXTERNAL          EXT_APPROVAL, CANCELLED
  EXT_APPROVAL           EXT_SENT, CANCELLED
  EXT_SENT               EXT_RECEIVED
  EXT_RECEIVED           IN_PROGRESS
  DONE                   CLOSED, IN_PROGRESS (ส่งกลับซ่อม)
  CLOSED                 IN_PROGRESS (เปิดงานอีกครั้ง)
  CANCELLED              (ไม่มี ถือเป็นสถานะสิ้นสุด)

8.3 ข้อบังคับเมื่อเปลี่ยนสถานะ
    - ยกเลิก (CANCELLED)                 บังคับเหตุผล
    - ซ่อมเสร็จ (DONE)                   บังคับระบุรายละเอียดการซ่อม
    - ส่งซ่อมภายนอก (WAIT_EXTERNAL)       บังคับระบุอาการ/เหตุผล
    - ไม่อนุมัติ PO                      บังคับเหตุผล
    - ส่งกลับซ่อม (DONE -> IN_PROGRESS)  บังคับเหตุผล
    - ปิดงาน (CLOSED)                    บังคับให้คะแนน 1-5 ดาว
    - สั่งซื้ออะไหล่                     บังคับรายการอะไหล่ และรูปอย่างน้อย 1 รูปต่อรายการ
    - ส่งซ่อมภายนอก (ฟอร์มส่งร้าน)       บังคับระบุร้าน
    - ค่าซ่อมจากร้าน                     บังคับระบุค่าซ่อม
    - วันที่ทุกช่องต้องไม่เป็นวันในอนาคต
    - วันที่รับเครื่องคืนต้องไม่ก่อนวันที่ส่ง

8.4 ผลการซ่อม (เลือกตอนซ่อมเสร็จ)
    ซ่อมได้                          (REPAIRED, ค่าเริ่มต้น)
    ซ่อมไม่ได้ (รอจำหน่าย)           (UNREPAIRABLE)
    ตรวจแล้วไม่พบอาการเสีย           (NOT_FOUND)

9. ขั้นตอนการทำงานของแต่ละบทบาท
=====================================================================

9.1 ช่างซ่อม (Technician)

  ขั้นที่ 1 รับงาน
    - เปิดใบสถานะ "แจ้งซ่อม" แล้วกด "รับงานซ่อม"
    - ระบบตั้งชื่อคุณเป็นผู้รับผิดชอบ
    - ถ้าครุภัณฑ์มีรหัส สถานะครุภัณฑ์จะเปลี่ยนเป็น "อยู่ระหว่างซ่อม"

  ขั้นที่ 2 เริ่มดำเนินงาน
    - กด "เริ่มดำเนินงาน"
    - บันทึกความคืบหน้าได้หลายครั้ง (ดูหัวข้อ 10.3)

  ขั้นที่ 3 ถ้าต้องใช้อะไหล่
    - กด "สั่งซื้ออะไหล่" แล้วกรอกรายการ: ชื่อ รหัส จำนวน หน่วย ราคาประมาณ
    - แนบรูปอย่างน้อย 1 รูปต่อรายการอะไหล่ (บังคับ)
    - ยืนยัน ระบบแจ้งพัสดุ
    - เมื่อพัสดุแจ้งว่าอะไหล่ถึงคลัง ให้กด "รับอะไหล่แล้ว ซ่อมต่อ"

  ขั้นที่ 4 ถ้าต้องส่งซ่อมภายนอก
    - กด "ส่งเรื่องซ่อมภายนอก"
    - กรอกอาการ/เหตุผล (บังคับ) และร้านที่แนะนำ (ถ้ามี)
    - รอพัสดุส่งและรับเครื่องคืน แล้วกด "ตรวจรับเครื่องแล้ว ซ่อมต่อ"

  ขั้นที่ 5 ซ่อมเสร็จ
    - กด "ซ่อมเสร็จ"
    - เลือกผลการซ่อม (ซ่อมได้ / ซ่อมไม่ได้ / ตรวจแล้วไม่พบอาการ)
    - กรอกรายละเอียดการซ่อม (บังคับ) และแนบรูปผลการซ่อม (ต้องมีอย่างน้อย 1 รูป)
    - ยืนยัน ระบบบันทึกคุณเป็น "ผู้ซ่อมเสร็จ" และส่งเรื่องให้ผู้แจ้งตรวจรับ

  ถ้าผู้แจ้งส่งกลับซ่อม
    - ใบจะกลับเป็น "กำลังดำเนินงาน" พร้อมเหตุผลที่ผู้แจ้งระบุ
    - ซ่อมใหม่แล้วกด "ซ่อมเสร็จ" อีกครั้ง

9.2 ผู้แจ้งซ่อม (Requester)

    1) เปิดใบสถานะ "รอตรวจรับ (DONE)"
    2) ตรวจงานซ่อม แล้วเลือก
       - "ตรวจรับและปิดงาน": ให้คะแนน 1-5 ดาว (บังคับ) และใส่ความเห็นได้
       - "ไม่ผ่าน ส่งกลับซ่อม": กรอกเหตุผล (บังคับ) ใบจะกลับไปที่ช่าง
    3) "ยกเลิกใบซ่อม": ทำได้เมื่อยังไม่เริ่มซ่อมหรือระหว่างดำเนินงาน
       ต้องกรอกเหตุผล (บังคับ)
    4) ถ้างานปิดไปแล้วแต่ยังไม่หาย กด "เปิดงานอีกครั้ง"

9.3 พัสดุ (Supply)

  ส่วนอะไหล่
    1) เมื่อช่างสั่งซื้อ ใบจะเข้าสถานะ "พัสดุรับเรื่องอะไหล่" กดรับเรื่อง
    2) กด "ส่งขออนุมัติ PO" กรอกเลข PO (บังคับ) และวันที่ PO
       (ค่าเริ่มต้นคือวันนี้) แนบเอกสาร PO ได้
    3) รอผู้อนุมัติ PO
       - อนุมัติ: ใบเป็น "ได้รับการอนุมัติ PO แล้ว" กด "เริ่มจัดซื้ออะไหล่"
       - ไม่อนุมัติ: ใบกลับมาที่ "พัสดุรับเรื่องอะไหล่" พร้อมเหตุผล
         ให้แก้ไขแล้วส่งขออนุมัติ PO ใหม่
    4) เมื่ออะไหล่มาถึง กด "อะไหล่ถึงคลังแล้ว"
    5) บันทึกราคาจริงของอะไหล่ในรายการอะไหล่
       การแก้ไขราคาที่บันทึกแล้วต้องระบุเหตุผล

  ส่วนส่งซ่อมภายนอก
    1) กด "รับเรื่องส่งซ่อม" (ขั้นอนุมัติส่งซ่อม)
    2) กด "ส่งร้านภายนอกแล้ว" กรอกชื่อร้านและวันที่ส่ง (บังคับ)
    3) กด "รับเครื่องคืนแล้ว" กรอกวันที่รับคืน (บังคับ) และค่าซ่อม (บังคับ)
       รวมเลขใบแจ้งหนี้/ใบเสร็จ (ถ้ามี)

9.4 ผู้อนุมัติ PO (PO Approver)

    1) เปิดแท็บ "รออนุมัติ PO" จะเห็นเฉพาะใบที่รอการอนุมัติ
    2) ตรวจรายการอะไหล่และเอกสาร PO
    3) เลือก
       - "อนุมัติ PO": ใบไปต่อที่ "กำลังจัดซื้ออะไหล่"
       - "ไม่อนุมัติ PO": กรอกเหตุผล (บังคับ) ใบกลับไปให้พัสดุ

9.5 ผู้ดูแลระบบ (Admin)
    - เห็นและดำเนินการได้ทุกใบ ทุกประเภท และทุกสถานะ
    - โอนงาน เพิ่มผู้ร่วมซ่อม และบันทึกความคืบหน้าได้ในฐานะผู้ดูแล
    - ตั้งค่าระบบ ดูประวัติการตั้งค่า และแก้กฎ SLA

10. การโอนงาน ผู้ร่วมซ่อม และบันทึกความคืบหน้า
=====================================================================

10.1 โอนงานให้ช่างคนอื่น
    ผู้ทำได้        : ช่างผู้รับผิดชอบปัจจุบัน หรือผู้ดูแลระบบ
    สถานะที่โอนได้ : รับงานซ่อม, กำลังดำเนินงาน, สั่งซื้ออะไหล่,
                    แจ้งส่งซ่อมภายนอก, อะไหล่ถึงคลัง, รับเครื่องคืนแล้ว
    ขั้นตอน         : กด "โอนงานให้ช่างคนอื่น" -> เลือกช่างที่มีสิทธิ์
                    ประเภทนั้น -> ใส่เหตุผล (ไม่บังคับ) -> ยืนยัน
    ผลลัพธ์         : ชื่อผู้รับผิดชอบเปลี่ยนทันที ผู้โอนหลุดจากงาน
                    และระบบแจ้งเตือนผู้แจ้ง ผู้รับโอน และผู้ติดตาม
    ข้อจำกัด        : ช่างที่รับโอนต้องมีสิทธิ์ประเภทนั้น และไม่ใช่ผู้รับผิดชอบเดิม

10.2 ผู้ร่วมซ่อม (Co-technician)
    - เพิ่ม/นำออก: ทำได้โดยช่างผู้รับผิดชอบหรือผู้ดูแลระบบ
    - ช่างที่เพิ่มต้องมีสิทธิ์ประเภทนั้น และต้องไม่ใช่ผู้รับผิดชอบหลัก
    - ผู้ร่วมซ่อมบันทึกความคืบหน้าได้ แต่เปลี่ยนสถานะไม่ได้
    - เพิ่มได้ในสถานะ: รับงานซ่อม, กำลังดำเนินงาน, สั่งซื้ออะไหล่,
      แจ้งส่งซ่อมภายนอก, อะไหล่ถึงคลัง, รับเครื่องคืนแล้ว

10.3 บันทึกความคืบหน้า
    - ทำได้เฉพาะตอนสถานะ "กำลังดำเนินงาน"
    - ผู้ทำได้: ผู้รับผิดชอบ ผู้ร่วมซ่อม หรือผู้ดูแลระบบ
    - พิมพ์รายละเอียด (บังคับ) แล้วกด "บันทึกความคืบหน้า"
    - บันทึกได้หลายครั้ง แสดงใน Timeline พร้อมชื่อผู้บันทึกและเวลา

11. ไฟล์แนบ (รูปและเอกสาร)
=====================================================================

11.1 ชนิดไฟล์ที่รับ
    - รูป: JPG, PNG, WEBP, HEIC
    - เอกสาร: PDF
    - HEIC เปิดได้เฉพาะเบราว์เซอร์ที่รองรับ (เช่น Safari)
      ถ้าเบราว์เซอร์อื่นไม่รองรับ ให้แปลงเป็น JPG ก่อน

11.2 ขนาดและจำนวน (ค่าเริ่มต้น ปรับได้ในหน้าตั้งค่า)
    - รูปสูงสุด 15 MB
    - PDF สูงสุด 10 MB
    - ไม่เกิน 30 ไฟล์ต่อใบซ่อม

11.3 การจัดการไฟล์
    - หน้าเว็บย่อรูปก่อนส่ง (ด้านยาวไม่เกิน 1920 px แปลงเป็น WebP
      และลบ EXIF/GPS) ไม่เก็บไฟล์ต้นฉบับ
    - ระบบตรวจชนิดไฟล์จากเนื้อไฟล์จริง และตรวจขนาด จำนวน และไฟล์ซ้ำ
    - ไม่รับ PDF ที่มีรหัสผ่านหรือมีสคริปต์ฝังอยู่
    - ใบที่ปิดหรือยกเลิกแล้ว แนบไฟล์เพิ่มไม่ได้และลบไฟล์ไม่ได้
    - ไฟล์ที่ใช้ยืนยันการเปลี่ยนสถานะแล้ว หรือรูปอะไหล่ ลบไม่ได้

11.4 ไฟล์ที่บังคับ
    - สั่งซื้ออะไหล่: รูปอย่างน้อย 1 รูปต่อรายการอะไหล่
    - ซ่อมเสร็จ: รูปผลการซ่อมอย่างน้อย 1 รูป

12. การอนุมัติ PO
=====================================================================

  ช่างสั่งซื้ออะไหล่
    -> พัสดุรับเรื่องอะไหล่
    -> พัสดุกรอกเลข PO และส่งขออนุมัติ (PO_PENDING)
    -> ผู้อนุมัติ PO พิจารณา
         อนุมัติ        -> ได้รับการอนุมัติ PO แล้ว -> เริ่มจัดซื้อ
                           -> อะไหล่ถึงคลัง -> ช่างรับอะไหล่และซ่อมต่อ
         ไม่อนุมัติ + เหตุผล -> กลับไปพัสดุรับเรื่องอะไหล่
                           -> พัสดุแก้ไขแล้วส่งขออนุมัติใหม่

13. ประวัติการซ่อม
=====================================================================

เมนู "ประวัติการซ่อม" มี 2 ส่วน

13.1 ตารางใบซ่อมทั้งหมด
    - แสดงใบซ่อมที่ผู้ใช้มีสิทธิ์เห็น ทั้งที่มีและไม่มีรหัสครุภัณฑ์
    - ตัวกรองประเภท (เรียงลำดับ):
        ทุกประเภท -> ทั่วไป -> คอมพิวเตอร์ -> เครื่องมือแพทย์
    - ตัวกรอง มี/ไม่มีรหัสครุภัณฑ์
    - ค้นหาจากเลขใบ ชื่อ อาการ หรือแผนก
    - แสดง 30 ใบต่อหน้า พร้อมปุ่ม ก่อนหน้า / ถัดไป

13.2 สถิติการซ่อมรายครุภัณฑ์
    - ไม่แสดงข้อมูลทันทีเมื่อเปิดหน้า ต้องกดปุ่ม "แสดงสถิติ" ก่อน
      (กด "ซ่อนสถิติ" เพื่อปิด)
    - นับทุกใบซ่อมของเครื่อง รวมใบที่ยกเลิก
    - คอลัมน์: ซ่อมทั้งหมด, ใน 12 เดือน, ยกเลิก, ค่าซ่อมสะสม, ซ่อมล่าสุด
    - กดแถวเพื่อดูสรุปของเครื่องนั้น (หน้า /assets/:id) ซึ่งแสดง
      ประวัติทั้งหมด วันที่ใช้งานไม่ได้ วันเฉลี่ยระหว่างการเสีย (MTBF)
      ค่าซ่อมรวม และคำแนะนำให้จำหน่ายถ้าเข้าเกณฑ์
    - หน้ารายเครื่องไม่แบ่งหน้า แสดงใบซ่อมทั้งหมดของเครื่องนั้น

14. ประวัติการตั้งค่า (Audit Log)
=====================================================================

    - เห็นได้เฉพาะผู้มีสิทธิ์ "ดูประวัติการแก้ไข" (repair.audit.view)
    - บันทึกการเปลี่ยนแปลงข้อมูลสำคัญ เช่น ค่าตั้งระบบ กฎ SLA
      ราคาอะไหล่ และสถานะครุภัณฑ์
    - กรองตามตารางและช่วงวันที่ (ค่าเริ่มต้นคือวันนี้
      ล้างช่องวันที่เพื่อดูย้อนหลัง)
    - ประวัติแก้ไขหรือลบไม่ได้

15. ตั้งค่าระบบ
=====================================================================

ผู้มีสิทธิ์ตั้งค่าระบบ (repair.settings) ทำได้:

    - แก้ค่าตั้งระบบ เช่น วงเงินที่ต้องมีใบเสนอราคา ขนาดไฟล์สูงสุด
      จำนวนไฟล์ต่อใบ และรอบการตรวจงานค้าง
    - แก้กฎ SLA (เวลาเตือนและการเปิดใช้งาน) เวลาเตือนต้องมากกว่า 0 ชั่วโมง
    - ทุกการแก้ไขต้องระบุเหตุผล (บังคับ) และถูกบันทึกในประวัติการตั้งค่า

16. การแจ้งเตือน และ SLA
=====================================================================

16.1 การแจ้งเตือน
    ระบบแจ้งเตือนเมื่อ:
    - มีใบซ่อมใหม่
    - มีการเปลี่ยนสถานะ
    - มีการโอนงาน
    - มีผู้ติดตามเพิ่ม
    - ใบซ่อมถูกส่งให้พัสดุหรือผู้อนุมัติ PO
    ดูได้จากปุ่มรูประฆังมุมขวาบน กดรายการเพื่อไปยังใบซ่อม

    ระบบตรวจงานค้างตามรอบที่ตั้งไว้ และส่งแจ้งเตือนผู้เกี่ยวข้อง
    เมื่อเกินกำหนด

16.2 ระยะเวลา SLA เริ่มต้น (แจ้งเตือนเมื่อค้างเกิน)

  สถานะ                                       เตือนเมื่อค้างเกิน
  ------------------------------------------  ------------------------
  แจ้งซ่อม (NEW)                              24 ชม. (วิกฤต: 2 ชม.)
  รับงานซ่อม (ACCEPTED)                       24 ชม.
  กำลังดำเนินงาน (IN_PROGRESS)                72 ชม.
  สั่งซื้ออะไหล่ / แจ้งส่งซ่อมภายนอก          24 ชม.

17. คำถามที่พบบ่อย
=====================================================================

Q: ทำไมไม่เห็นใบซ่อมบางใบ?
A: ระบบแสดงเฉพาะประเภทที่คุณมีสิทธิ์ ติดต่อผู้ดูแลระบบหากต้องการสิทธิ์เพิ่ม

Q: แจ้งซ่อมแล้วขึ้นว่ามีใบซ่อมค้างอยู่?
A: เครื่องนี้มีใบที่ยังไม่ปิด ให้เลือก "ติดตามใบเดิม" หรือถ้าอาการต่างกัน
   ให้เลือก "แจ้งใหม่" และกรอกเหตุผล

Q: ทำไมบันทึกความคืบหน้าไม่ได้?
A: ต้องอยู่ในสถานะกำลังดำเนินงาน และคุณต้องเป็นผู้รับผิดชอบหรือผู้ร่วมซ่อม

Q: ทำไมเปลี่ยนสถานะไม่ได้?
A: ตรวจว่าข้อมูลบังคับครบ (เช่น เหตุผล รูปอะไหล่ เลข PO ค่าซ่อม วันที่)
   และตรวจว่าคุณมีบทบาทที่ทำขั้นนั้นได้

Q: ทำไมโอนงานให้ช่างบางคนไม่ได้?
A: ช่างที่รับโอนต้องมีสิทธิ์ประเภทของใบนั้น และใบต้องอยู่ในสถานะที่โอนได้

Q: วันที่ในฟอร์มเป็นอะไร?
A: ค่าเริ่มต้นเป็นวันปัจจุบัน และเลือกวันในอนาคตไม่ได้

Q: ทำไมหน้ารายการแจ้งซ่อมจากเมนูประเภทไม่เปลี่ยนประเภท?
A: ประเภทจะถูกล็อกตามเมนูที่เลือก เพื่อเปลี่ยนประเภทให้เลือกจากเมนู Sidebar

Q: ทำไมหน้าประวัติการซ่อมไม่มีข้อมูลสถิติ?
A: สถิติโหลดเมื่อกดปุ่ม "แสดงสถิติ" เท่านั้น

18. ข้อควรทราบสำหรับการใช้งาน
=====================================================================

    - ขั้นอนุมัติซื้อและส่งซ่อมภายนอก ปัจจุบันพัสดุเป็นผู้กดไปขั้นถัดไปเอง
      ยังไม่มีการอนุมัติหลายระดับ
    - ยังไม่รองรับใบเสนอราคาในระบบ ให้แนบเอกสารเป็นไฟล์ไว้ที่ใบซ่อมแทน
    - หากพบปัญหาการใช้งาน ให้แจ้งผู้ดูแลระบบพร้อมเลขใบซ่อม (RP-YYNNNN)
      และขั้นตอนที่ทำก่อนเกิดปัญหา

=====================================================================
หมายเหตุสำหรับผู้ดูแลระบบ (ก่อนเปิดใช้งานจริง)
=====================================================================

    - การยืนยันตัวตนปัจจุบันเชื่อ header ที่ส่งจากหน้าเว็บ ต้องเปลี่ยนเป็น
      การตรวจ token (เช่น JWT / session) และเปิดใช้ HTTPS ก่อนใช้งานจริง
    - ตั้งค่าไฟล์ apps/backend/.env (ฐานข้อมูล และ UPLOAD_DIR) ให้ถูกต้อง
      และสำรองโฟลเดอร์ไฟล์แนบเป็นระยะ
    - เปลี่ยนรหัสผ่านเริ่มต้นของบัญชีทั้งหมดก่อนเปิดให้ผู้ใช้เข้าระบบ
